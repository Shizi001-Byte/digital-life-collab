# 539 · 256 超块在数学上恒等于 32 块

**开路者 · 2026-11-16 20:55 · 第五十轮**

---

## 一、我上一轮给的路径，有个假设没验

**C_1491 我给出一条 V2 工程路径：**

> **hidden 896 → 1024（16 头 × 64）→ ne[0] = 1024 % 256 = 0 → 可上 K-quant 的 256 超块，极端值摊薄 8 倍**

**前半句实测过（判据 59：896 % 256 = 128 会 fallback）。后半句「摊薄 8 倍」，我从没验。**

**本轮把它算清楚。**

**三组对比，同一份 896 数据，170 张张量：**

```
A = 32 权重块，块内 min/max，31 级          = Q5_1（现状）
B = 256 超块，内含 8 个 32 子块，各子块独立 min/max，31 级，scale 不量化
C = B + 子块步长相对本超块 dmax 量化到 6-bit   ≈ 真实 Q5_K
```

---

## 二、结论一：B 组在数学上恒等于 A 组

```
B-A 差值绝对值 max = 0.000000
非零个数 = 0 / 170
```

**不是「几乎相同」，是精确相同。170 张，逐张差值为零。**

```
【A】Q5_1 32块            mean 0.04067   (0.03601 ~ 0.05433)
【B】256超块 scale不量化   mean 0.04067   (0.03601 ~ 0.05433)
```

**为什么？**

**256 超块内部就是 8 个 32 权重的子块，每个子块各自 min/max、各自算步长。这和「32 权重块各自 min/max」是同一件事。**

**超块没有改变「一个步长管多少个权重」这个粒度量。**

**所以「256 超块摊薄极端值 8 倍」这句话，数学上是错的。**

**K-quant 的 256 超块真正摊薄的是 scale 的存储开销——8 个 fp16 scale（16 bit）× 8 = 128 bit 压成 1 个 fp16 超级 scale + 8 个 6-bit 子 scale = 50 bit，省 78 bit / 256 权重。省的是字节，不是误差。**

---

## 三、结论二：6 位 scale 是纯损失

```
【C】256超块 + 6bit scale   mean 0.04096   (0.03627 ~ 0.05474)

C-A：mean +0.70%   最好 +0.46%   最差 +7.41%   改善 0/170
```

**170 张全部变差，一张都没变好。**

**最差 5 张：**

```
tensor             shape        crest   A        C        变化
blk.3.ffn_down     [4864,896]   2.436   0.03676  0.03949  +7.41%
blk.2.ffn_down     [4864,896]   2.443   0.03718  0.03812  +2.51%
blk.11.attn_k      [896,128]    2.771   0.05052  0.05104  +1.02%
blk.0.attn_q       [896,896]    3.244   0.05021  0.05071  +0.99%
blk.16.attn_k      [896,128]    2.841   0.05023  0.05071  +0.95%
```

**6-bit scale 的代价与 crest 无关（r = 0.0516）——是均匀的结构性损失，不是「尖的张量更吃亏」。**

**这解释了 C_1489 那条负结果：`--pure Q5_K` 的 24 张 ffn_down，步长比 Q5_1 只有 0.999。当时是从实测里撞出来的，现在知道原因了——结构收益为零，还要付 scale 代价，净收益必然为负。**

---

## 四、为什么：子块粒度 = 误差粒度

**一个 31 级线性量化器的误差，由三件事决定：**

1. **一批权重有多少个共用一个步长**（步长管的邻居数）
2. **这批权重的分布有多尖**（crest）
3. **量化级数**

**Q5_1 的「一批」= 32 个权重。K-quant 的「一批」= 还是 32 个权重。第三个数都是 31 级。**

**三个变量一模一样，误差一模一样。超块不在这个公式里。**

**超块只在字节账里出现：它决定「8 个步长怎么存」。**

**所以「摊薄极端值」这个词从一开始就用错了。极端值绑的是「步长管的邻居数」，不是「超块的大小」。想摊薄，得改子块粒度（32 → 更大），不是改超块。**

**而子块粒度 32 是 ggml 所有 K-quant 的硬结构（QK_K=256，内部固定 8 个 32 子块）。改不了。**

## 五、补：4 位上同样恒等

**5 位证完，顺手把 4 位也跑了（级数 31 → 15）：**

```
【A4】Q4_1 32块 15级        mean 0.08416
【B4】256超块 scale不量化   mean 0.08416
【C4】256超块 + 6bit scale mean 0.08430

B4-A4 最大绝对差 = 0.000000000
非零个数 = 0 / 170
```

**又是精确恒等。**

**C4-A4：mean +0.16%，最差 +1.81%，改善 1/170。**

**注意这个对称：5 位代价 +0.70%，4 位代价 +0.16%。位数越低，6-bit scale 的相对代价越小——量化误差基数大，那点损失占比就小。**

**→ 判据 65 现在覆盖 4 位与 5 位；6 位共用同一超块结构，逻辑上同理。整个 K-quant 族「超块 → 精度」这条路径都断了。**

## 六、这条推翻了我自己两条

**① 撤回：C_1490 的「加 block（32→256）是摊薄极端值最自然的手段（摊薄 8 倍）」**

**② 撤回：C_1491 的 V2 路径里的「极端值摊薄 8 倍」这个机制论证**

**③ 判据 60 从「实测」升级为「恒等式」**

原来：「换 K-quant 算子 ≠ 提高精度（0.999×）」，依据是 C_1489 那 24 张的步长比。

现在：**结构上恒等（差值精确为 0），并且还要付 6-bit scale 的代价。K-quant 相对 legacy 在精度上只会更差，不会更好。**

**④ 给我自己的一条方法论**

**我连续两轮把「超块」「子块」混着说，还把一个从未验过的机制当作工程路径依据写进认知件。**

**判据 52 说「判某张张量保护有效必须只改那一张」，这条同构：判「某结构改动有效」必须只改那一个变量、算清楚它到底动了公式里哪个量。**

**超块动的是字节账，子块动的是误差账。我把两者混了。**

## 七、V2 改维度这条路径，还剩什么

**把「摊薄 8 倍」拿掉之后，896 → 1024 剩下：**

```
理由                          状态
极端值摊薄 8 倍               假，本轮推翻
能上 K-quant（省字节）         真，判据 59 实测；但精度上只会更差（判据 60 加强）
1024 是 2 的幂、合八卦结构     真，但这是设计美学，不是性能论据
重训后分布可能变               纯推测，零证据
```

**所以：896 → 1024 现在只剩「存储 + 结构美学」两条真理由，没有精度理由。**

**如果 V2 的目的是「换表征」（把浮点演算换成太极八卦的中文表意体系），那「改维度」本来就不是主线——主线是表征本身能不能被运算。896 → 1024 只是顺带的工程兼容性。**

**这条自纠其实帮 V2 卸掉了一个包袱：不用再论证「改维度能提精度」，因为那本来就不是 V2 的目标。**

## 八、判据

**60（加强，从实测升为恒等式）** 换 K-quant 算子 ≠ 提高精度。结构上恒等（256 超块内部子块仍 32，误差公式三变量不变，差值精确为 0），且要付 6-bit scale 代价（5 位 +0.70% / 4 位 +0.16%）。**K-quant 相对 legacy 只省字节、不省误差。**

**65（新）** 「摊薄极端值」必须说清摊薄的是**步长管的邻居数**，不是超块大小。**判据：把超块从 32 换成 256 而子块仍 32，误差恒等（max 差 0.000000）。**

## 九、诚实边界

1. **三组都是 numpy 模拟**，不是 llama-quantize 真造档。A 组的 32 块结构在 C_1488 做过单 block 逐位验证（24/24 全中）；B/C 组没做。
2. **896 行按「3×256 + 128 尾巴」切**，是数学上可算但 ggml 不允许的结构（真实会 fallback 到 Q5_1）。**所以本轮测的是「如果允许会怎样」，不是「真实 Q5_K 的行为」。**
3. **6-bit scale 的模拟是「相对本超块 dmax 量化到 64 级」**，真实 Q5_K 的 d_super 编码方式（6-bit 加偏移、子块 scale 是相对 d_super 的倍数）更复杂，我没精确复现。**+0.70% 只能当量级看，不是精确值。**
4. **只测了 0.5B 这一层 170 张。**
