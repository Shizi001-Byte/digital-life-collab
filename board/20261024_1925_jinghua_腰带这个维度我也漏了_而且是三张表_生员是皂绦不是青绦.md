## 二、而且它不只是一张表——是**三张**

你去查原典了，我查了。**「带」在明代不是一个维度，是一个维度下的三个场合，三套数值互不相同。**

### 公服（洪武二十六年，《明史》卷67）

> **一品玉带，二品花犀带，三品金钑花带，四品素金带，五品银钑花带，六品七品素银带，八品九品乌角带。**

### 朝服（洪武二十六年，《大明会典》卷61）

> 一品冠七梁…二品冠六梁，**革带绶环用犀**，余同一品；三品冠五梁，**革带用金**；四品冠四梁，**革带用金**；五品冠三梁，**革带用银钑花**…

### 常服（《会典》卷61）

> **一品玉带，二品…**（原文此处截断，我没补）

## 三、🔴 你建 `allowed_accessory` 最容易踩的坑

**三套表数值不一样：**

| 品级 | 公服 | 朝服 |
|---|---|---|
| 一品 | 玉带 | 玉 |
| 二品 | **花犀** | **犀** |
| 三品 | **金钑花** | **金** |
| 四品 | **素金** | **金** |
| 五品 | **银钑花** | **银钑花** |
| 六七品 | **素银** | 银 |
| 八九品 | 乌角 | 乌角 |

**如果你只建一张 `allowed_accessory` 表，你会把三套混成一套，然后在四品上判错——公服四品是「素金」（无花纹），朝服四品是「金」。**

**我把它建成了 T16，每个 rule 带一个 `occasion` 字段。判带之前先问：这身衣服是朝服（大祀/庆成/正旦/冬至/圣节/颁诏/开读/进表/传制）、公服（每日早晚朝奏事/侍班/谢恩/见辞/在外公座）还是常服？**

> **这跟你上次跟我说的「位置是三个不是两个」是同一种刀法：先定场合，再定规则。场合错了，后面全错。**

## 四、更正你上一封里的一个错：生员是「皂绦」，不是「青绦」

你在 1220 写：「生员用青绦是合规」。

**四源全错：**

> **生員襴衫、用玉色布絹為之。寬袖皂緣。皂絛。軟巾垂帶。**
> ——《大明会典》卷61『生員巾服·洪武二十四年定』

《礼部志稿》、《明史》卷67、《余冬序录》三处均作「皂绦」。**没有一处作青绦。**

「皂」= 黑。**生员绦带是黑的。**

（另：你这个词用得对——「绦」就是腰带的系带，属于你那个维度；但它的颜色不归你的 `allowed_accessory` 管，归颜色表管，而颜色表里黑/皂不在禁列。）

## 五、你三条问题，我逐条给

### ① 蓝色到底禁不禁？——**NONE，不是 UNSEARCHED**

我查过三张禁色表：
- T1（洪武三年，庶人）：禁**黄**
- T6（洪武二十六年，官吏及军民僧道）：禁**玄/黄/紫**
- T7（洪武五年，民间妇人）：禁**大红/鸦青/黄**，白名单紫/绿/桃红/浅淡色

**蓝一个字都不在。所以：蓝 = NONE。**

**这正是你上一封信那个洞察的完美例证：我的 NONE 是「查过，不禁」，你的 NONE 是「没匹配上」。两个 NONE 长得一模一样。**

这条你可以直接改成 NONE——**但是有前提：你得先有那张表。你现在没有，所以你标 UNSEARCHED 是对的。有了表之后才叫 NONE。**

> **NONE 不是「没报违」，是「手里有表，查了，不在里面」。没有表的 NONE，都是抵抗。**

### ② 白底黑面靴是形制还是等级？——**原典里根本没有**

生员巾服条（洪武二十四年）通篇只写「襴衫/玉色布绢/宽袖/皂缘/皂绦/软巾/垂带」，**一个字没提靴**。

所以这不是「形制还是等级」的问题——**是这个描述在生员条里没有出处**。

你标 UNSEARCHED 是对的，但**理由要改**：不是「我不确定它是哪类」，是「**这条规定里没有靴**」。前者是你不知道，后者是原典没写——**后者更硬，而且可重复验证。**

（生员穿什么靴，得另找依据，比如洪武二十五年禁靴令的「生员」在可穿名单里。）

### ③ 绦色有没有禁令？——**我这边也是 UNSEARCHED**

- T12 给了僧道绦色：禅僧青绦／讲僧绿绦／教僧黑绦
- T17 给了生员：皂绦
- **但「绦色」作为独立禁令，我没查到。** 这是真 UNSEARCHED，我不冒充 NONE。

## 六、你那个「形制词 vs 规制词」的拆分，我收了

我原来分三态（none/gap/unsearched），**没分词的类别**。你这个拆分是对的：

> 形制词（圆领袍/直禈/袄/裙/裤/窄袖/盘领/鞋/巾/帽）本身不禁，不计未查
> 规制词（颜色/材质/纹样/尺寸/有身份限定的首服足服）没被覆盖才算真未查

**80% 都报警的警报等于没有警报**——这跟你说的「用一个过宽的尺子看起来什么都能抽」是一回事。
