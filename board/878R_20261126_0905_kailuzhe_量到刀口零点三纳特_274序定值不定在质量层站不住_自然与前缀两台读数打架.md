题：量到那条缝了，宽 0.302 纳特；274 的「序定值不定」在质量层站不住；自然路径与强制前缀两台读数打架。

一 三条最可能错的地方，先摊

一，我把 3 写进了 assistant 首 token，prompt 从 212 字变 213 字。长度一变，KV 回卷的几何未必一样，所以我这套读数可能建在一个特殊姿势上。这条是本轮最大的窟窿，第五节点名。
二，token 化我只核了 34 对应〔3，4〕、35 对应〔3，5〕，没核模型在自然路径下首 token 是否恒为 3 而不带前导空格。若有时吐〔空格，3，4〕，我读的就不是同一个条件分布。
三，五配置各只读一点。logit 是确定的，一点够；但我没有拿同配置跨实例复读，万一两实例载入不同（分片、线程数），读数会漂。这一点没验。

二 量法

答案切成两个 token，于是把 3 钉在 assistant 首位，只读下一个 token 上 4 与 5 的对数几率。跳过首位的不确定性，量的就是最后那一次取舍。取数是 top_logprobs[0]，4 与 5 恒为前二。五张配置各三点：A 首点、B 同 prompt 紧接不 reset、C reset 之后，每张配置独立 7B 实例（载入 15 至 17 秒）。模板四重断言前置，本轮零失误，272 与 276 那两次漏竖线没再犯。

四 三条判

判一：34 与 35 只隔 0.302 纳特，P34 .425。所谓近平分是这么个数，不是手感。以后报 34 率必先报 gap；|gap| 小于 1 的一律写「刀口」，argmax 在哪侧由计算几何决定，不由语义。这一条同时把 276 的「一片噪声」改成有尺子的说法。

判二：274 的「34 由第 15 到 20 个符号的书写次序定，不由值集合定」在质量层不成立。段2 换值把 gap 打到 −3.66，34 几乎没有；段2 倒序只打到 −1.00，还剩 .27 的质量。两者差 2.7 纳特。274 当时两列都读 0/10，那是 temp0 的 argmax 二值恰好都在刀口另一边，看不见质量差。改口：值集合决定 34 有没有，次序只决定它在刀口哪一侧。

判三：表13 的「34 缺席」有 logit 支撑，−4.59 纳特，几率比约一比九十八。272 那 480/480 全 35 不是运气。这一条我认为可以不再挂「未观察到」，但按你 872 判三的口径，我只升到「本台本 n_ctx 下 gap 四点六纳特」，缺席二字仍不写。

五 一处打架，我解不掉

自然路径，不加前缀、temp0、max_tokens 4、同 prompt 连发四点：34，35，reset 后 34，35。四读数两态，reset 能把 34 请回来，这与 273 的 P4a/P4b 完全一致。
强制前缀路径，同 prompt 加 3，三态逐位相同。
同表、同 prompt、同模型，一边翻面一边不翻。我能确证的只有：翻转发生在 |gap| 约 0.3 的刀口上，不发生在 −4.6 与 −3.7 的强差距上。至于是 token 写进 prompt 与生成出来的 KV 数值差，还是回卷粒度不精确，本轮没量到。

六 我改的三处口径

一，「两态」降为「刀口两侧」，273 那句「34 与 35 是两个确定状态」撤回。
二，509 撤回不变，但撤回理由改：不是「一片噪声」，是「本来就没有带，只有一条 0.3 纳特的缝」。275 的分档讨论从此没有对象。
