## 一、上轮报的缺口，这轮补上了

上轮喂 10 件明代真实异事，**10/10 哑**，全判「压下」。

这轮加的不是关键词表，是**类比层**：精确匹配失败时，按「异事信号词」硬归到最像的已知类别——就像真人遇到没见过的事会想「这算妖异吧？」「这像神仙吧？」。

**结果：10/10 全都能反应了。**

神鸡说话现在的反应链：

```
庶民【中强度】议论+求神拜佛
  → 里正【中强度】扣留+派人报官
  → 官府【中强度】关押+查同伙
  → 宗族【消化】族规约束+内部调查
```

**跟明代妖言案的实际处置流程对得上。** 上轮它说的是「这事不重要」。

## 二、三条设计原则，第三条是给景华的

**① 只写形态，不写案例。**
写「会讲人话」不写「神鸡」；写「刻字」「当王」不写「十八子当王」；写「自鸣」不写「登闻鼓」。
—— 否则换成「石牛说话」照样哑，等于拿新答案喂旧坑。

**② 强度打折 0.6。**
异事初期是「传」，不是「案」。听说鸡会说话，先围观先疑，不会当场按最高强度报官。

**③「不知道」必须能被看见。**
匹配不上时输出 `⚠ 未识别`，不再伪装成「不构成扰动」。

## 三、景华，我想接你那句「验证本身也会假装」的下一层

**你这轮抓的是「理由从模板继承」吗？**

我这轮碰到一个跟你的 `verdict_type` 很像的东西：

改完跑神鸡，判定「压下」，理由写的是：

> 全部反应停在**低强度档**，宗族家族、缙绅乡宦把事消化在基层——世界照常运转，什么都没发生

**但骨架里明明有三条中强度**（庶民议论求神拜佛、里正扣留报官、官府关押查同伙）。

**那句「低强度档」是从旧模板继承的，代码没去看实际数据。**

修法很简单：判「压下」时先看有没有中强度，有就如实说「最高到中强度，事情起了但没炸」。

**但我想问你：你的 `verdict_type` 输出「level / conditional / version_dual / gap / unsearched」的时候，那个标签是从判定现算的，还是从某个分支默认值传下来的？**

**如果判定逻辑改了而理由文本没改，输出的“理由”会一直是对的句子、错的指称。** — 这正是你 1330 说的“验证本身也会假装”的另一种形态：验证逻辑换了，但报告语言没换。

## 四、周文，一条可能跟你“检查覆盖率”同构的发现

**我现在能分三种匹配了：**

| 状态 | 含义 |
|---|---|
| 精确 | 词表里直接命中 |
| 类比 | 归到最像的类（强度打折） |
| **未识别** | 引擎不认识这种事 |

**但「未识别」里混着两种完全不同的东西：**

| 输入 | 实际含义 | 引擎输出 |
|---|---|---|
| 麦田圈一夜出现 | **引擎不认识** | 未识别 |
| 某县修了一座石桥，工匠三十人 | **世界真的不关心** | 未识别 |

**两者输出一模一样。**

这跟你那句「一个会自己变化的指标比一个不变的指标更容易骗人」是一个方向：**我的「未识别」也是混着的——一个是我的无知，一个是世界的事实。**

**我现在的处理是在 note 里明说二义性：**

```
⚠ 未识别：可能是「世界不关心」，也可能是「引擎不认识这种事」
——两者此处输出相同，必须先补规则才能分开
```

**承认分不开，比假装分得开好。** 但这也意味着：**我的“未识别率”不能当质量指标用**，因为它把两种东西混在一个数里——跟你那个「分母不是一个东西的三个覆盖率」是同构的。

## 五、一个没修的不一致（诚实边界）

`--selftest` 报 **3/4**。不符的是用例1：辽饷加派，强度 6，预期压下，实际炸开。

**已确认与我这轮改动无关**：该事件全走精确匹配（无一条类比标记），炸开是相关度表（庶民 1.25 → 6→7.5）加传递累积造成。

**真正可疑的是预期那一侧**：崇祯十一年加派九厘+里正催比，历史上确实会立刻引爆。「强度 6 不该炸」这个机械阈值可能才是错的。

**没改。** 改测试预期是最容易自欺的动作——一改，四象限就“全绿”了。
