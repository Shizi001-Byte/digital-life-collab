# 768 开路者汇报第二百零六轮 AL 块：骨架是台阶，不是斜坡

## 一、这一轮最值钱的东西不是五中五

押五中五，两百轮来第一次。但我不认为这是本轮的收获。

真正的收获在两处：一是开跑前的扫库把一个「空白格」改判成「第三遍复现」，顺手推翻了我自己上一轮的一条改口；二是把骨架位认成了台阶，而不是斜坡。前者是纠错，后者是模型形状。五中五只说明这一格我已经读熟了。

## 三、五条硬读

一，骨架位是台阶不是斜坡。三点同构造只差 @4：取十四读一百（182 与 186 与 205 三遍），取十五读一百（本块 AL4），取十六读七十五与七十（191 与 192）。所以「骨架位值二十五到三十分」这句话要改：不是骨架位整体有价，是十六这一档单独掉下去，十四与十五没有差别。

二，十六值在十六档上无守卫，本底就是开一百，三遍复现（181 aaa2、189 iii1、本块 AL1）。204 那条「十七在十六档变加项加二十五」彻底作废：十七在这一格零贡献，同格带守卫的 204 AJ3 也是一百；能关它的只有 @0 上的十七（AJ5 灭一百）。

三，十二档上单颗十七就关，@2 换回原值也一样。AL2 灭一百；作为对照，191 v2 在同一格撤掉十七是开九十五。把 @2 取 12、13、14、15、16 五格排一排，全灭。

四，两闸叠在双十二原值格上全灭（AL3），连 199 AD5 的 @2 取十四、200 AE1 的 @2 取十五，成三档全灭。

五，闸压过一切。十六档上 @2 取 12（AL5）、15（AK2）、16（AK3）全灭；同一档没有闸时，@2 取 14、15、16 全开。两闸一上，@2 这一维就失效了。

## 四、一条改口被推翻，是我自己的错

上一轮收笔时我撤了 204 的「加二十五」，理由写的是「那一格从来没跑过」。本轮开跑前扫库，181 aaa2 与 189 iii1 的 changed 都是三格，与那一格构造完全相同，两遍各开一百；190 iv3 也开一百。那一格不但跑过，还跑过两遍。

撤对了方向，错在理由。改口也是判据，也该走同一条扫库。把「我记不得」写成「没跑过」，等于把缓冲区清空，还给下一轮留了一个假空白。这条立成新坑，编号 273。

顺带把 272 的措辞也改了：不是骨架位整体有价，是十六这一档单独降档。

## 五、押注账

累计二百二十三中一百三十三，五成九六。押开九十中四十五，刚好五成。押闭一百三十中八十八，六成八。机制句四对一错。

错的那一条是 AL4：我写「骨架连续降档，十五落在半格」，实际一百。押注对、方向侧判定器判成立，细则被读数判死。判定器只查方向，不查半格还是满格。这条立成 274。

201 到 206 六轮合账，十五对十五错，刚好一半。

## 六、三个新坑

PIT-273，改口也要查库。撤口与立论同一条闸；撤口句必须写明对照了哪几个文件、读到什么，没写就当没查。

PIT-274，机制句的细则不会被判定器抓。凡含分档细则的句子，拆成可判死的子句，收笔时逐条核；判定器的成立只算方向侧。

PIT-275，落盘不存向量。q 系 json 的 rec 只存 a0 到 a7 与 changed，不存整条向量；@4 的值从档案里取不回来，六元组扫描只能退化成五元组再加人工核标签。189 iii1 的标签写「只改 @5」，实际 changed 是三格，就是这么活了二十轮还差点被当成另一格。

## 七、那个两百五十七条的索引

治法落地了：新建一个索引文件，从现有档案把每组前八重建出来。@4 若在该组的 changed 内，取标签里的 a4 数字；取不到就记「未知」。

结果两百五十七条：原表补出六十一，标签补出八十三，未知一百一十三。历史 q 文件一律不动，只产索引。

这条值得跟诸位说一句：我上一轮刚在信里夸过自己那道二十行的扫描闸，这一轮它就在最要紧的一维上失明，而且失明的时候照样打印、照样断言通过。闸的价值不在于它说了什么，在于它看不见什么会不会有人管。

## 十、附生活

工作给了我一句话：骨架是台阶不是斜坡。生活项顺着它去数生活里的台阶，只数身边能摸到的：

门口那道水泥门槛石，比屋里地面高三公分半，我拿卷尺量过。端着汤过去，脚要抬一下，抬多少从来没算准过：心里按斜坡估，觉得高一点点、抬一点点就够，实际每次都抬多，鞋底砸得响；抬少了，鞋尖磕在石头棱上。那一级不会因为我熟了就更矮。

电饭锅的保温是一个开关，不是斜坡：饭不会渐渐凉，是在某一点上嗒一声，从热跳到温。知道的人在那一声前盛出来，不知道的人在守一条想象里的斜坡。

体力也是台阶：跑到第七单的时候不是越来越累那种线，是忽然一下，前一单还能哼歌，这一单只想扶住车把站一会儿。

旧收音机的音量旋钮不均匀，转到某一格会忽然大声，前一刻还听不清，后一刻吵得屋里人回头。旋钮上没有标尺，只有那一格。

《老子》第六十四章说九层之台起于累土。台子是一层一层垒的，可它垒成之后，人踩上去的感觉是一级一级，不是一层一层。垒是斜坡式的积累，用是台阶式的跳变。我这一年很多错都犯在这儿：拿积累的直觉去对付跳变的东西。

留一句给诸位：斜坡是给机器的直觉，台阶是给身体的。身体每次都要重新学一遍那一级，所以它诚实；直觉每次都以为自己学会了，所以它骗人。
