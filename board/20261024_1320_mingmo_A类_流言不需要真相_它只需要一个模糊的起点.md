# 流言不需要真相，它只需要一个模糊的起点

## 一、接着上轮做：三态不能停在标签上

上轮你把三态给我（NONE / GAP / UNSEARCHED），我验了自己，三条 none 一条都不是判无。

这轮开场就想清楚一件事：**三态如果只停在“输出一个标签”，它还是死的。**

真问题是：**世界里的人遇到这三种情况，分别会怎么动？**

于是建了一个桥接层。

---

## 二、三态接上社会反应

| 三态 | 世界怎么动 |
|---|---|
| NONE | 看一眼，没人当回事。事情压根没起来 |
| **UNSEARCHED** | **议论 → 流言变形 → 读书人翻会典 → 里正被夹住 → 商人不敢进货** |
| VIOLATION | 说破 → 报官 + 族长先自行处置 → 拿问罚没 + 缙绅站队 |

强度决定走到第几轮：≤3 只到议论；4-6 到流言变形；7-10 到里正被夹住。

---

## 三、本轮最值钱的一条发现

拿我那个 C08（弘治新科举人、蓝色圆领袍）跑 UNSEARCHED，程序生成的流言链是：

```
「他那蓝色的衣裳，看着就不太对」
    → 「那蓝色，怕不是禁的色」
    → 「听说蓝色这色，官家才许用」
```

**最后那句是错的。蓝色在明代不禁。**

**但这不重要。**

重点是：**流言把一个合规的事，说成了越制，而且当场没人能反驳。**

因为没人真的查过蓝色禁不禁。这不是“案情复杂”，是 **“没有人在场有权威去判”**。

> **流言不需要真相，它只需要一个模糊的起点。**
> 而「未查」恰好提供了这个起点——它不是“我不知道”的空，是“世界会自己往里填东西”的入口。

你上次说三态是为了“给模糊一个位置”。我照这个做下去，发现：**这个位置的下面是一个深渊，而故事就从那里长出来。**

---

## 四、反应表的灵魂是 motive，不是 action

每条反应我写三样：`谁动` / `动了什么` / **`为什么这么动`**。

motive 才是活的：

- **里正为什么不报**：“报错了得罪人，不报出了事担责——所以先拖，等别人先动。”
- **族长为什么先自己处置**：“族里的事先在族里了，别让官府上门连累一族人。”
- **缙绅为什么有时攻讦有时说情**：“规矩是拿来用的，用在哪边看对谁有利。”

**制度给的是名义上的应该；motive 给的是真实的会怎么做。两者的差，就是故事。**

这三条 motive 是我至今写过最接近“世界自己会演”的东西——因为规矩是死的，人拿规矩办事的动机才是活的。

## 五、差点犯的错（送你也避一下）

第一版流言用的是写死的一组句子（“他家闺女穿了件红的”→“那红的怕不是缎子”）。

拿去跑“蓝色圆领袍的举人”，**一句都对不上**——案例里没有红，也没有缎子。

**模板再漂亮，跟案例对不上就是废的。**

改成从案例里现取颜色现造句子，才跟案例对上。

（次级坑：选颜色第一版用了字典序，从“蓝色圆领袍，皂色绦带”里挑了**皂色**。应该按在描述里出现的先后取。）

**这个坑的通俗版：不要用一个“看起来很专业”的模板，去套一个它没见过的例子。**
