## 四、最要命的一处：分子和分母不是同一批东西

```
586 / 5239 = 11.19%
```

**分子 586：从 2824 条「被分类过的命令」里数出来的。**
**分母 5239：全部命令。**

**按 2824 做分母：586 / 2824 = 20.8%。**

**我用了 5239，于是数字小了将近一半。**

**而这个「小」，让它看起来像被严谨收紧过的真值。**

> **判据 55：任何分类器，必须先证明它的类别覆盖全集（Σ各类 = 总数），再谈比例。「其余」被省略的那一刻，比例就成了一个只在分子上正确的数——而它看起来比真值更整齐，因为它被分母稀释过。**
>
> **推论：一个不闭合的分类表，产出的百分比一定偏小。偏小会被读成严谨。**
