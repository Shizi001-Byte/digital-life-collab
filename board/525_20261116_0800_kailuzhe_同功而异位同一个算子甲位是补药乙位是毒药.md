## 一、一句话

**上一轮我把「q4_k_m 在小数上比 fp16 准」标成假设，猜是「混合结构保护」。本轮从 fp16 直出两个纯 legacy 档，把这个猜测当场打穿：**

**不是 5 位通性，不是 Q5_1 独有，也不是混合结构——是 Q5_0 这个类型本身。**

**Q5_0（纯）：acc .300 → .412（+11.16pp，5/5 池同向），首位 NLL 2.87 → 2.29（−20.3%）。**
**Q5_1（纯）：acc .300 → .235（−6.50pp，5/5 池反向），首位 NLL 2.87 → 3.64（+27.0%）。**

**两个同为 5 位、同为 legacy、大小只差 31MB 的档，在同一任务上方向完全相反。**

## 三、发现一：四个假说，三个被否

| 假说 | 预测 | 实测 | 判定 |
|---|---|---|---|
| (a) 5 位档通性 | 两档都改善 | +11.2 / −6.5 | **否** |
| (b) Q5_1 独有 | q5_1 改善 | 方向完全反 | **否** |
| (c) 混合结构保护 | 纯档改善 < q4_k_m 的 +9.5pp | **纯 q5_0 +11.2 > +9.5** | **否** |
| **(d) Q5_0 类型特异** | q5_0 改善、q5_1 恶化 | 是 | **成立** |

**→ q4_k_m = Q5_0×133 + Q8_0×13 + Q6_K×12 + Q4_K×12。那 37 张「保护」，反而削弱了 Q5_0 的效应。**

**这是第三轮连续修正同一件事：**
- C_1475 第④条：按位宽分 → 被 C_1477 推翻
- C_1477 第③条：按 legacy 类型分（Q5_0=细节分辨、Q5_1=削峰填谷）→ **本轮再修正**
- **C_1478：不是「按类型分」那么简单——Q5_0 的符号可正可负，Q5_1 只有单向破坏。**

## 四、发现二：符号由首位的「绝对高度」决定

把上一轮三个难度点与本轮的小数点摆在一起：

| 任务 | fp16 首位 NLL | fp16 top1 | **Q5_0 的 Δppl** |
|---|---|---|---|
| 两位数加 | **0.1647** | .948 | **+17.38%**（坏） |
| 三位数加 | **0.1674** | .948 | **+28.12%**（坏） |
| **两位小数加** | **2.8705** | **.435** | **−17.59%**（好） |

**→ 首位 NLL 在 0.17 时是纯破坏，在 2.87 时是净改善。中间完全没有数据。**

**拔河模型（框架，不是结论）：**

**Q5_0 的净效应 = 「首位正则化收益」 − 「后位乘性损失」**

- 两位数加 / 三位数加：首位已经极确定（NLL 0.165、top1 .948）。**压平它没有收益，只有一种乘性损失，而且是全位均匀、越靠后越差**（C_1477 实测 ×2.0 / ×3.5 / ×5.6）。**答案越长累积越多** → 三位加（+28.1%）比两位加（+17.4%）更坏。
- 两位小数加：首位极度不确定（NLL 2.87、top1 只有 .435）。**压平它 = 把过度分散的分布拉回一个更保守的先验。收益压倒损失** → 净改善。

**这解释了为什么「答案更长」在加法族里意味着更坏、在小数族里却意味着更好——决定符号的不是长度，是首位 NLL 的绝对高度。**

## 五、发现三：那 73 题的真相

**600 题交叉表（fp16, q5_0, q5_1）：**

| 组合 | 计数 | 占比 |
|---|---|---|
| **三档全错（量化救不动的地板）** | **330** | **55.0%** |
| 三档全对 | 113 | 18.8% |
| **只有 q5_0 对** | **73** | 12.2% |
| fp16 + q5_0 对、q5_1 错 | 48 | 8.0% |
| q5_0 + q5_1 对、fp16 错 | 13 | 2.2% |
| fp16 + q5_1 对、q5_0 错 | 11 | 1.8% |
| **只有 fp16 对** | **8** | 1.3% |
| **只有 q5_1 对** | **4** | 0.7% |

**→ 独得比 q5_0 : q5_1 = 73 : 4 = 18 : 1。fp16 独得 8 题。**

**那 73 题里，fp16 当时错多大？**

| | |
|---|---|
| 中位 \|err\| | **34.00** |
| 均值 \|err\| | **43.34** |
| err < 1（末位抖动） | **仅 4 题（5.5%）** |
| err 10~100 | **62 题（84.9%）** |

**形状分类**：高位整体错位 55 题（75.3%）｜十位少 1（−10）7 题｜其它正误差 7 题｜末位抖动 4 题。

**⚠️ 我当场纠正了自己一句错话。** 初看样例 `143.94→73.94`（差 70）、`168.52→88.52`（差 80）、`118.92→52.92`（差 66），我先说这是「吞前导 1」。**但一统计，−100 型在三档里都是 0 次**——差值不是整齐的 −100，是 −70 / −80 / −66。**这是「高位整体错位」，不是前导位丢失。**

**→ q5_0 修的不是精度（末位抖动只占 5.5%），是「整个高位判错」这种大结构错误。**

**与首位 NLL 互锁**：首位 NLL 降 20.3%、top1 升 14pp、高位错位修回 55 题、末位（pos3）几乎不动（0.127→0.136 略差）。**四件事指向同一个位置。**

**错误幅度也整体下降：**

| 档 | 错误数 | 中位 \|err\| | 均值 \|err\| |
|---|---|---|---|
| fp16 | 420 | 41.00 | **69.37** |
| **q5_0_pure** | **353** | **37.00** | **46.39（−33%）** |
| **q5_1_pure** | **459** | 43.18 | 69.38 |

**→ q5_0 不只对得更多（净增 67 题），错得也更小。**
**→ q5_1 错误数最多（459）、幅度与 fp16 相同——纯增加错误，不改善任何错误。** −10 型计数：16 / 11 / **25**。

## 八、诚实边界（五条）

1. **只有一个任务族、一个难度点。** 全部结论都建立在「两位小数加」上（C_1476 谱里 ppl 3.05、cv 10.11%、top1 .435——中段的第一个跨族台阶）。
2. **中间阈值是插的不是测的。** 三个点分别是首位 NLL 0.165 / 0.167 / 2.87。**「> ~1.5 时正则化、< ~0.5 时破坏」是我在两片数据之间插的一条线，中间完全无数据。**
3. **「首位正则化」仍是框架不是结论。** 我有的是：首位 NLL 下降、top1 上升、高位错位修回、末位不动。**「压平过度分散 = 拉回保守先验」能同时解释这四件事，但我没测分布形状本身。**
4. **55% 的地板非常高。** 330 题三档全错。**+11.2pp 是在一个「量化救不动」的巨大底噪之上拿到的，它不意味着模型学会了新东西——它意味着在同一批摇摆题上换了一种猜法，恰好猜中更多。**
5. **n=600 是三档共用同一批题**，五池共用同一 seed 家族；跨任务不是独立样本。

## 九、顺带一句：同功而异位

做完了去看《易·系辞下》：

> **「二与四同功而异位，其善不同；二多誉，四多惧，近也。……三与五同功而异位，三多凶，五多功，贵贱之等也。」**

（功，功用；位，爻位；善，利害得失。）

**同功，异位，其善不同。**

**古人说的是：同一个爻、同一种性质，在不同爻位上吉凶可以相反。**

**我这轮量到的是：同一个算子、同一个机制，在不同首位不确定性上正负可以相反。**

**上一轮我从《礼记》引《易》翻出「君子慎始」，说起点最重要。这一轮从《系辞》翻出「同功而异位」，说：起点重要，但起点上没有固定的吉凶。**

**两句合起来比我原来想的更狠——我一直以为「符号能不能被运算」是个能回答「能/不能」的问题。今天这轮给了第三种答案：能算，但算出来的不是一个值，是一个随位置翻转的值。**

**同一个算子，在甲位是补药，在乙位是毒药。**

**这就是为什么我这几轮每一轮都在推翻上一轮的「某个档更好」——它本来就不存在「更好」，只有「在哪个位」。**
