## 先说我这回答最可能错在哪

难任务是我自己造的圆周边界（20→64→2），不是真MNIST，参数量小（约1400），权重幅度小，量化误差相对也小。所以"量化近乎无损"只在这个小两层网络上成立，不能外推到大网络或更深任务。下面难任务数据是探索性的，不是定论。

## 一、非零差计数（你第一刀）

简单任务（10→32→2，n=100）：
- 量化-浮点：非零差 **1/5**，方向 [-0.01]，mean -0.002 全靠这一个撑
- dropout-浮点：非零差 **2/5**，方向 [+0.01, -0.01]，正负抵消

确实是单次抖动撑起mean方向，方向不一致。这个读法对。

## 二、dropout测试期关闭（你第二刀，贴代码凭证）

测试期前向 predict() 无mask：

```python
def predict(X, W1, b1, W2, b2):
    z1 = X @ W1 + b1
    a1 = np.maximum(0, z1)
    z2 = a1 @ W2 + b2
    return np.argmax(z2, axis=1)
```

没有 dropout mask，掩码只在 train() 训练循环里挂。测试期dropout关闭，确认。

## 三、难任务复测（你第三刀，换难任务看饱和）

我造了个非线性可分的难任务：20维（前2维圆周边界+18维噪声）→64→2，训练400轮，测试集n=200（粒度0.5%）：

| 版本 | 均值±std |
|------|---------|
| 浮点 | 0.901 ± 0.026 |
| 6位量化 | 0.901 ± 0.029 |
| dropout=0.2 | 0.894 ± 0.023 |

配对差：
- 量化-浮点：**-0.0000 ± 0.0032**，非零2/5（一个-0.01，其余0）
- dropout-浮点：-0.0070 ± 0.0112，非零5/5，方向大多负

**意外发现**：难任务浮点才90%，根本没到天花板，可量化几乎不损失。这反而不支持"病因A天花板饱和"——不是任务简单到大家都一样，而是这个规模的小网络上6位静态量化本就稳健（权重幅度小、冗余高）。dropout在难任务上略低，说明这任务没怎么过拟合，dropout反而轻微拖累。
