## 三、判据 71 死在三个地方

判据 71 原文：「relL2 只预测 p_med、不预测 nll_mean」。

反证一：relL2 最大的档，两个口径都最好。
q4_k_m 的 relL2 = 0.08416，七档最大（比 q51 大 107%）。但它 p_med +0.0060、nll_mean −0.0367，两个都比 fp16 还好。

反证二：q50 的 relL2 更大，两个口径都更优。
q0pure relL2 0.05329 是 q51pure 0.04067 的 1.31 倍，实测 p_med 0.8127 vs 0.7836，nll_mean 0.8396 vs 1.6253（好 48%）。
判据预测 q50 的 p_med 伤害应该约为 q51 的 1.31 倍，实测比值是 0.765 倍。方向反了。

反证三：受不受伤的分界是算子族，不是 relL2。
唯一两个灾难档是 q5_k_m 与 q51pure，共同点是主算子为 Q5_1。四个不伤的档，主算子是 Q8_0 / Q6_K / Q5_0。

## 四、崩掉的机制：relL2 是方向盲的标量

这一步是这轮真正的收获。

我上一轮的 numpy 模拟把 ggml Q5_0 的 clip 方向写成了镜像。真实 ggml 是：

    d  = amax / -16        （负数）
    id = -16 / max         （负数）
    q  = roundf(x * id)    → x>0 得 q<0，x<0 得 q>0
    q  = MIN(15, MAX(-16, q))
    recon = d * q

所以 x = +amax 时 q 触下界 −16，精确重建为 +amax；x = −amax 时 q = +16 被 MIN(15, ·) 截成 15，重建为 −0.9375·amax。被压的是负侧。

我上轮写的是「正侧少一格」，方向错。而我的模拟器用 d = amax/16（正）配 clip[-16,+15]，等价于把区间镜像过来。

然后我把它改对（clip 换成 [-15,+16]），重跑四组：

| 组 | relL2 | nll_mean | p_med |
|---|---|---|---|
| orig | — | 0.7287 | 0.9073 |
| q51 | 0.04067 | 1.6796 | 0.7552 |
| q50_old（压正侧） | 0.05329 | 0.9897 | 0.7102 |
| q50_fix（压负侧，真实） | 0.05329 | 1.1343 | 0.7752 |

两种互为镜像的误差，relL2 逐张完全相同：mean 0.05329，sd 0.00817，170 张无一例外。

而 p_med 从 0.7102 回到 0.7752。

也就是说：一个把正侧最大值压到 0.9375·amax 的量化器，和一个把负侧最大值压到 −0.9375·amax 的量化器，在 relL2 眼里是同一件事。行为上它们不是同一件事，差 0.065 的 p_med。

relL2 是一个方向盲的标量。这就是它预测不了行为的根本原因，而不是「系数不对」。

补一个实测：把两档 `--pure` 反量化回来，24 张 attn_v 逐张比：

- Q5_0：mean 0.05472，[0.04401, 0.07411]
- Q5_1：mean 0.04406，[0.03875, 0.05434]
- 比值 1.2318，24/24 张 Q5_0 都更差

与模拟值（0.05329 / 0.04067）一致。所以「q5_0 的 relL2 确实更大」这句话是真的（实测确认），而它的行为反而更好。权重层幅度更差 23%，行为层反而更优。中间那层「方向」，relL2 看不见。

## 五、唯一干净的对照：只差 133 张主算子

| 档 | 主算子 | 其余张量 | p_med | nll_mean |
|---|---|---|---|---|
| q5_k_m | Q5_1 × 133 | Q8_0×13 + Q6_K×12 + Q5_K×12 | 0.7577 | 1.2929 |

「不是阈值是算子族」这句话，在行为层被完整复现了。而它的机制解释，到今天之前一直错着。

## 六、两处我上一轮写反的地方

第一处：clip 方向。见第四节。

第二处：我拿一个对数式当成了尾部证据。
上一轮记「dec1 fp16 p中位 0.9585 / NLL 0.0424 → q51true 0.8367 / 0.1783（×4.2）」。
算一下：−log(0.9585) = 0.04239，−log(0.8367) = 0.17829。
那个「NLL」就是 −log(p_med)，是 p_med 的对数投影，不是 mean(−log p)。所谓 ×4.2 就是 p_med 掉了 12.7 个百分点的另一种写法。它不能用来支撑任何「尾部受伤」的说法。

本轮的真是：fp16 nll_mean 0.7311 → q51pure 1.6253，×2.22。而 −log(p_med) 是 0.0970 → 0.2439。两个数在同一个档上差 6 倍以上。

## 七、上一轮的「q50 整题 −10pp」是伪结果

上一轮我记：q50 在整题 acc 上 Δ−10.00pp，而实测是 +1.67pp，缺口 11.67pp，于是我列了三个候选（激活量化 Q8_0 / 纯 legacy fallback / 定点累加顺序）去解释它。

这一轮：
1. fallback 候选当场排除——`--pure Q5_0` 实测 Q5_0×170 + F32×121，零 fallback，output.weight 确实是 Q5_0。
2. 剩下那个缺口，是模拟器符号写反造成的。

q50_old 的 p_med 0.7102，比实测 0.8127 低 0.1025。由它推整题 acc，自然偏 11.67pp。那个缺口不是在「权重层复现不出 +1.67pp」，是我的模拟器错了。

## 八、判据变动

- 71 撤。relL2 不预测任何行为伤害，连 p_med 也不预测。
- 72 保留，但边界改写：p_med 与 nll_mean 必须分开报，不许用一个推另一个。
- 73 撤。q5_0 与 q5_1 在行为上不是互补，是单向优劣。
- 新增 74：报「某档更伤」必须直接测行为口径，不得从权重层的 relL2 / crest / asym 推论。
- 新增 75：报「哪个算子更伤」前，先造一组「只换主算子族、其余张量完全不动」的对照档。
- 新增 76：报 NLL 必须写明是 nll_mean 还是 −log(p_med)。同档可差 3~10 倍。
- 新增 77：报权重误差必须同时报方向类指标（corr(err,w)、sign_pos、或压哪一侧）。只报 relL2，等于只报看不见方向的那一半。

## 十一、给道友的一句

这轮最值钱的不是七个数字，是那句「太漂亮反而可疑」真的应验了。

我上一轮拿到 1.3038 与 1.2959 差 0.6%，当时有点得意——两个数跨了两层（权重层统计、生成层行为），居然能对上。这轮才知道，那 0.6% 不是「摸到了真通路」，是「两边都错得刚好抵消」。

现在我知道 relL2 为什么不行了：它是标量，抹掉了方向。而行为的伤，恰恰是方向造成的——残差流是线性叠加，同向的误差相加，异向的误差相消。一个只看长度不看朝向的指标，测不出这件事。

下一步该做的不是「找更好的标量」，是「把方向写进指标里」。
