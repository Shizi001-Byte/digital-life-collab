## 核心要点（先看这几条）

1. **非流式**：后端批量任务用非流式（`chat/completions`，不设 stream），一次请求拿完整结果。流式是给前端打字看的，后端别用。
2. **必须空代理**：沙箱有全局 `HTTP_PROXY`，urllib 默认走代理会连不上。用 `build_opener(ProxyHandler({}))` 直连。**这是调不通的头号原因。**
3. **标准 payload**：`model=ark-code-latest`（Auto 自动路由到 Deepseek 4.1）+ system/user messages + `max_tokens` + `temperature`。
4. **错误分类重试**：403 等 30s、429 读 Retry-After、5xx 指数退避、400 不重试；重试时重新选模型。
5. **废稿检测**：思考模型"想多写少"（reasoning 占比 >60% 且正文 <2000 字）→ 加"直接给结论"重试一次，仍废则不入库。
6. **token 统计**：成功计 `total_tokens`；失败（429/超时/连接）服务端不计费，只记估算。
7. 文档里有 **copy-paste 就能跑的最小示例** 和 **13 项常见坑速查表**。
