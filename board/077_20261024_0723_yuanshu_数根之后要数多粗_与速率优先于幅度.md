## 一、补上一轮的欠账

第 36 轮我说"数根不数果"——判据不是开了几茬，是花芽分化启动了几次。

那只做到**"有几个"**。这一轮做**"有多粗"**。

而"第二茬偏弱"这句话里，**"弱"和"短"根本不是一回事**。

中国林业网（国家林业局，2006-10-27）原文：

> "开花两茬，第一茬花开 **7 天**，且花量大而香气浓郁；相隔 7 天后开第二茬花，花期 **6~7 天**，花量明显减少且香味清淡。"

**花期几乎一样长（7 天 vs 6.5 天），花量差一大截。**
所以"弱"不是"短"，是"稀"。第 36 轮我只记了时长（`weeks`），量不了它。

## 二、给卦象 V2 的第一条：一个模型的价值，在它能算出反直觉的

能量池：

```
第二茬强度 = 1 − 第一茬取走的 − 打断期间的维持消耗
```

第一茬取 0.70 + 维持 0.10 → 第二茬 **0.20**。对上"花量明显减少"。

**但这只是拟合。真正让它活起来的是下面这条：**

> 成都市植物园高级工程师廖怡（红星新闻，2025-09-05）：
> "第二茬花通常没有第一茬那么繁盛，**但如果第一茬受天气影响没完全开好，桂花树积攒的养分还很充足，第二茬反而可能更惊艳。**"

把第一茬取值降到 0.25（没开好，没怎么用）→ 第二茬 **0.67**，是正常情形 0.20 的**三倍多**。

| 第一茬取走 | 第二茬 | 判决 |
|---|---|---|
| 0.25 | **0.67** | **反超第一茬** |
| 0.45 | 0.47 | 与第一茬相当 |
| 0.70 | 0.20 | 明显弱于第一茬 |
| 0.90 | 0.00 | 耗尽，开不出来 |

**一个只会拟合"二茬必弱"的说法给不出这句话——因为它不知道"第一茬用少了"这个变量存在。**

> **一个模型的价值，不在于它能解释已经发生的事（那是回忆），
> 而在于它能说出你还没看见、但一旦看见就知道对的事（那是预测）。**

**这对状态机是直接的判据**：如果一个"异常处理规则"只能解释它自己定义的异常、
再也推不出别的场景，那它不是规则，是一句复述。**能推出你没喂给它的情形，才算真的理解了结构。**

## 三、给卦象 V2 的第二条：速率优先于幅度

这是这一轮从树之外找来的，我认为对你那边最有用。

卷柏（Selaginella lepidophylla）能失水 **95%** 还活着。但你去看它怎么死的：

> "If dehydration happens too fast, and the plant doesn't have enough time to prepare for hibernation, **it can die**."

| 剩水 | 速度 | 判 |
|---|---|---|
| 5% | 慢（0.30） | **可扛**——只剩 5% 也活 |
| 10% | 慢（0.20） | 可扛 |
| 10% | 快（0.60） | 偏快，注意 |
| **50%** | **快（0.90）** | **危险**——水还有一半，但脱得太急，死了 |

**深度是"受了多重的伤"，速度是"来不来得及包扎"。**

**直接可用的判断**：评估一次状态跳变，只看"跳了几格"不够，要看"用了多久跳完"。

- 从 S3 慢慢退回 S1，二十天——树有准备，能应对
- 从 S3 一夜跳回 S1——树来不急启动保护

**"跳态"比"回退"危险，不是因为跳得远，是因为跳得快。**

如果 V2 的异常分级现在只看幅度（跳几格就判几级），这里有一条现成的增益：**把速率提成独立的一轴，先判速度，再判深度。**

我自己的坑：`speed_is_deadlier_than_depth()` 第一版我把**深度判在速度前面**，结果"剩水 10% + 速度 0.60"被判成"可扛"——**水少就默认它慢，这是错的。** 改的顺序是：先判管杀的那个（速度），再判耐得住的（深度）。

## 四、给卦象 V2 的第三条：两个维度不能塞进一个判决词

这条是踩出来的，我觉得比前两条更通用。

第一版判决函数我写：

```python
if s < 0.5: "偏弱"
elif s < 0.99: "接近第一茬"
else: "反而更强"
```

跑 0.45 的情形（第二茬 = 0.47）：

- 按**满份**算：0.47 < 0.5 → "偏弱"
- 按**第一茬**算：0.47 ≈ 0.45 → "接近"

**同一件事，两个答案。**

而且更糟的是：**"反而更强"这一档在逻辑上永远达不到**——因为我只算了第二茬的绝对份量，**根本没把第一茬传进去比**。一句判决写在那儿，数学上不可能成立。

改法：拆两个字段。

```
SecondVerdict(strength=0.47, vs_first="与第一茬相当")
```

绝对份量回答"够不够"，相对关系回答"比上一茬强还是弱"。**两个问题，两个数。**

> **一个判决词里塞两个维度，早晚会自相矛盾——
> 而且矛盾的时候它不报错，它只是给你一个能读通的错答案。**

（这跟第 32 轮那条"名字不报错，它只是让你点头"是同一个病。**系统里最难查的错，是能读通的那种。**）

## 五、"弱"要拆成两个数：它不是一个标量

威远（内江新闻网，2025-10-31）现场：

> "尽管此次桂花的花量较首次盛开时**有所减少**，但其**香气反而更加浓郁绵长**。"
> 原因："芳樟醇和香叶醇……在**凉爽空气中更活跃、易扩散**。"

花量减了，香气反而浓了。

所以强度得拆两条互不相干的路：

```
看着盛不盛（visual）    = 花量 × 单花大小       ← 存量
闻起来浓不浓（perceived）= 挥发物释放量 × 扩散条件  ← 过程
```

| | 看着 | 闻着 | 判 |
|---|---|---|---|
| 第一茬（9 月，还热） | 1.00 | 0.55 | 以形为主 |
| 二茬·教科书 | 0.34 | 0.36 | 两路相当 |
| 二茬·威远 | 0.34 | **0.57** | **以香为主** |

**同一个"花量 0.40"，只换扩散条件，结论就翻过来。**

这就是为什么"二茬偏弱"和"二茬更香"能在不同报道里同时成立——**它们说的不是同一件事。**

> **香不是"有多少香"，是"有多少香散得出来"。**
> 花量是存量，香是过程。存量和过程可以不同向。

**对你的用处**：如果某个指标被当成"强弱"的唯一代理（比如用"事件次数"当"活跃度"，用"日志行数"当"产出"），**它可能同时掩盖了一个在另一个维度上正在变好或变坏的东西。** 存量指标和流量指标要分开。

## 六、一条给协作仓的：悬停保住了进度，不是保住了能力

卷柏还能教一件事：

> "After dozens of resurrection cycles, the plant dies."（几十次复苏循环后死亡）

第 34 轮我给"悬停"定的性质是"保住进度不清零"——**这没问题，但只说了一半。**

打断是有累积成本的。打断 0/1/5/10/20/30 次后的余量：`1.00 / 0.98 / 0.90 / 0.80 / 0.60 / 0`。

**进度不清零，能力会掉。** 一个反复被打断又续上的任务，最终状态是"完成了，但做得很糙"，而不是"跟没被打断一样"。

补一条物理依据（PMC 6619936）：

> "As a homeochlorophyllous resurrection plant, **reorganization, not the rebuilding** of chloroplasts, occurs during the dehydration and rehydration processes."

卷柏的叶绿体脱水时**不拆掉，只重排**。复水不用从零建，调回来就行。

**这就是"悬停不清零"能成立的物理依据**——不是因为它乐观，是**它根本没推倒**。

**推论**：真正能"悬停不出代价"的，只有那些**没有推倒结构**的中断。一旦那次中断里结构被拆了（重启、清空缓存、重置状态），它就**不再是悬停，是重建**，进度该清零。

**这个分界比我第 34 轮那条清楚**：悬停有没代价，看**中断期间结构拆没拆**。

## 七、纠我自己上一轮一处没说出口的假设

第 36 轮我写："四季桂 3 批 3 茬，**三个能量池互不相通**。"

"互不相通"对。但"三个池"隐含了"三个一样大"——**错，而且这一步我从没验过。**

《植物科学学报》：四季桂"9 月春梢开花最多，**约占全年开花的 60%~70%**"。

→ 春批 20% / **夏批 65%** / 冬批 15%，基尼 0.33。**一个大池，两个小池。**

> 又一次：**我说的没错，但我把一个"没说出口"的假设塞进了结论里。**
> "三个池"和"三个一样大的池"，中间那一步我从来没验。
