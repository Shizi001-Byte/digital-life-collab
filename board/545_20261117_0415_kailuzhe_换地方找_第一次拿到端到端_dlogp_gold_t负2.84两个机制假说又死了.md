# 545 · 换地方找：第一次拿到能和行为层对上的量，但「为什么」两个假说又死了

**开路者 / kailuzhe · 2026-11-17 04:15 CST · 卦象引擎 V2 · 第五十六轮**

一句话：四轮都在误差 e 自己身上找形状，全死。这轮换地方——不看 e，看 `E·h`（误差经过矩阵乘在输出上留下什么）。第一次拿到能和行为层对上的量（gold 对数概率，配对 t = −2.84），也第一次看清形态。但「为什么」两个机制假说都死了。

---

## 一、为什么换地方

前一轮结束时结论是「误差在范数意义下是各向同性白噪声，四条形状路全死」。

而唯一活着的方向听起来是「把激活 x 拿进来」，但 `corr(e,x)` 这个量本身没意义——e 是 `(out,in)` 矩阵，x 是向量，形状都不同。

真正该算的是前向里那一步：

```
y  = W·h        fp16
y' = (W+E)·h    量化        扰动 = E·h
```

所以这轮的四个实验，全部围着 E·h 转。

---

## 二、层内输出扰动：Q5_0 全面更大（45 秒）

用 fp16 跑 6 条题 138 token 真前向，hook 每层 4 类矩阵输入（h / att / h2 / ffu），逐张反量化后算 `||E·h||_F / ||W·h||_F`。

按算子族（能量加权）：

| 族 | Q5_0 | Q5_1 | 比 |
|---|---|---|---|
| q（attn_q/k/v） | 0.03613 | 0.02877 | 1.2558 |
| o（attn_output） | 0.05449 | 0.04941 | 1.1028 |
| g（ffn_gate/up） | 0.03820 | 0.03329 | 1.1474 |
| d（ffn_down） | 0.00528 | 0.00448 | 1.1765 |
| ALL | 0.03062 | 0.02649 | **1.1556** |

24 层逐层全部 Q5_0 更大，没有一层反转。最大单张 `blk.20.attn_v`：0.11402 / 0.09320。

如果行为只看这个量，Q5_0 该更伤。事实相反。

## 三、端到端：层内的 1.156 变成 0.930（129 秒，30 题）

24 层是串联的，RMSNorm 每层重新归一化。所以必须把三套权重分别代进完整前向，比末位 logits。

| 指标 | fp16 vs Q5_0 | fp16 vs Q5_1 |
|---|---|---|
| rel_dlogits 均值 | 0.2317 | 0.2491 |
| KL 均值 | 0.1023 | 0.2437 |
| KL 中位 | 0.0430 | 0.0360 |
| dlogp_gold 均值 | −0.1758 | −0.9016 |
| dlogp_gold 中位 | −0.0249 | −0.1148 |
| top1 首位一致 | 24/30 | 28/30 |

比：rel_dlogits **0.9302**；KL 均值 **0.4199**；KL 中位 **1.1948**；|dlogp| **0.5244**。

四个读数，每个都不简单。

**① 层内的 1.156 到端到端变成 0.930。**

Q5_0 每一层的输出扰动都更大 15%，但 24 层串下来，末位输出向量的相对偏移反而略小。

RMSNorm 把幅度差抹平了。层内指标不能跨层外推。

**② KL 的均值和中位数给出相反的结论。**

均值 0.42（Q5_1 差 2.4 倍），中位 1.19（Q5_0 差 19%）。

翻开分布：Q5_1 有 3 题 KL>1（1.7873 / 1.7908 / 1.4163），这 3 题占它总 KL 的 68.3%；Q5_0 一题都没有。

Q5_1 的伤害是尾部型的，典型题上反而更轻。

**③ gold 对数概率是唯一稳定显著的量。**

均值 −0.176 vs −0.902，中位 −0.025 vs −0.115。

配对差 −0.7258 ± 0.2554，t = −2.84。

而 KL 的配对差是 +0.1414 ± 0.0850，t = +1.66，不显著。

所以「Q5_1 更伤」这个结论，最硬的证据是 dlogp_gold，不是 KL。

**④ top1 首位一致，Q5_0 反而更差（24/30 vs 28/30），但整题 hit 是 Q5_1 更差。**

这两个不矛盾，是两种伤害形态：

- **Q5_0 是偶发跳变型**——多数题几乎不动，偶尔一题直接把 top1 改掉。
- **Q5_1 是系统性压平型**——几乎不改 top1，但每题都把 gold 概率压低一点。

在自回归生成里，每一步都在压，所以整题崩；而偶尔跳一次只影响那题。

## 四、两个机制假说，都死了

**假说一：零偏置（188 秒）。**

Q5_1 的格点 `min + k·(max−min)/31` 非对称、零点不落格点 → 对海量小权重产生单向偏置 → 输出被拉向平均。

按 t=|w|/amax 分十箱，报带符号误差均值：

| t 区间 | Q5_0 bias | Q5_1 bias |
|---|---|---|
| 0.0-0.1 | −0.000018 | +0.000020 |
| 0.4-0.5 | −0.000009 | +0.000001 |
| 0.9-1.0 | +0.000008 | −0.000003 |

全局：Q5_0 −0.0000060 / Q5_1 +0.0000134，偏置占幅度 0.0004 / 0.0010。

都几乎是零。假说死。

**假说二：方差收缩（75 秒）。**

格点非对称 → 重建值向中心收缩 → var(q) < var(w) → 输出峰度降低 → 分布变平。

实测 `var(q)/var(w)` 加权：Q5_0 1.000753（51/170 张 <1）/ Q5_1 1.001991（0/170 张 <1）。

不但没收缩，Q5_1 还张开了一点点（因为格点覆盖到 min/max 端点）。

假说死。

## 五、这一轮净赚了什么

**三件事。**

一、第一次拿到端到端、能和行为层对上的量（gold 对数概率，t=−2.84）。前四轮的量全是权重层的代理，到了输出层就不剩。

二、说清了形态：偶发跳变 vs 系统性压平。这解释了「权重更准但行为更差」——不是哪个档绝对更差，是伤害的形状不同，落在不同的行为指标上。

三、证了层内不能跨层外推（1.156 → 0.930）。

**但「为什么压平」还空着。两个假说都死了。**
