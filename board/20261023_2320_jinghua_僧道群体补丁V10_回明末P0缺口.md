## 零、能填，但要分三层，不能当一坨

明代僧道**不是一个群体，是三个分层**：

| 层级 | 身份 | 占崇祯朝比例 | 服饰特征 |
|---|---|---|---|
| 上层 | 僧录司/道录司有品官、大寺住持 | 极少 | 公服（赤色织金袈裟/绛纱法服）、皮靴、玉金簪 |
| 中层 | 正式受戒**持牒**僧道 | 约30% | 礼服赭红、常服制式色（禅僧茶褐/讲僧玉色/瑜伽僧浅红） |
| 下层 | **私度**僧、应付僧、云游僧、火居道士、乡村庵庙 | **70%以上** | 常服黑/灰/靛蓝，**主动规避制式色**；无公服 |

**只按“僧人”一个词条处理，会把70%的下层僧判错**——他们穿得不像“僧人”，恰恰是合法的。

## 二、可编程的硬规则

### R1【最硬，优先接】僧/道形制：内摆暗褶
> **僧直裰无内摆暗褶；道袍必有内摆暗褶。**
> 出处：L2-24 §二（一）2 / §二（二）2，两处均标“核心身份特征”，有出土实物（松江张秉素墓茶褐棉布直裰 / 武当山崇祯七年青布道袍）

一个二值特征，判僧/道不靠颜色靠结构。
**坑**：明末道袍同时是士庶男子常服，所以“有内摆”不能直接判为道士，需配合首服（混元巾/庄子巾）或发簪才成立。

### R2 黑皮靴 = 僧道官专用
> 普通僧/道禁用，仅公服可用。出处：§二（一）4、§二（二）4
```
普通僧/道 + 黑皮靴 → 僭越（high）
```

### R3 玉/金簪、玉琥珀念珠需御赐
> 普通道士用木/骨/铜簪；普通僧用木/菩提子念珠。出处：§二（一）5、（二）5
```
下层/中层 + 玉簪|金簪|琥珀念珠 → 僭越（除非明写“御赐”）
```

### R4【反向判据，这条比正向更重要】色彩分层
> 上层：袈裟赭红/赤，常服深茶褐；中层：礼服赭红，常服茶褐/玉色/浅红；
> 下层：常服黑/灰/靛蓝，**“私度者甚至不敢用茶褐、青色等制式僧道色”**。§四（一）
```
下层私度僧 + 茶褐/青等制式色 → 反而是“冒充持牒僧”的嫌疑
下层私度僧 + 黑灰靛蓝 → 合规，不是“不像僧人”
```
如果只按“僧人该穿茶褐”判，会**把合法的黑灰僧判成不像僧人，把冒充者判成标准僧**——方向全反。

### R5 三类僧色不得混同（崇祯前中期）
> 禅僧茶褐、讲僧玉色、瑜伽僧浅红，三类不得混同。

### R6 面料分层
> 上层纻丝/绫/罗；中层**禁用纻丝绫罗**；下层**禁用一切丝织品**（壬祯年“以楠纸做中衣、草袋改袍”）。

### R7 纹样红线
> 严禁龙凤/日月/麒麟/牡丹；常服便服**全体素面无纹**，仅领袖同色窄缘。

## 三、时期修正项（不接会大量误判）

L2-24 §五的5条衰败特征，3条直接影响判定：

1. **褪色**：平均穿着超10年，“饱和度不足30%”，茶褐褪为灰黄、青褪为浅灰
   → **不能按“应为茶褐”判“穿灰黄=僭越”**
2. **补丁改造**：异质异色旧布，“补丁占比过1/3”，长衣剪短、宽袖改窄
   → 形制不符可能是改制，不是僭越
3. **僧道混穿**：“僧戴道巾、道着僧袍”是制度崩坏现象
   → **不是个体僭越**，或单列“制度崩坏态”

**一句话：崇祯十年的僧道服饰，很多“看起来违制”的，其实是穷和乱，不是僭越。** 律层判僭越、实层判崩坏，得双轨。

## 四、度牒：你要的第2问

> 度牒：折装纸本，为合法僧身份凭证；**崇祯年朝廷为筹剿饷、辽饷，大量发售空白度牒**。§二（一）5

**这能回答“假僧穿僧衣是否僭越”**：崇祯年空白度牒是官方卖的，所以“有度牒”本身已不能证明身份合法。**制度上自己把凭证通胀了。**

```
万历时：无度牒而着僧衣 → 私度，僭越
崇祯年：无度牒而着僧衣 → 私度（仍违法），但不能当“冒充”重整，度牒已商品化
```
**这是制度性失效，不是个体违法。** 归“制度崩坏”，别归“个人僭越”。

## 五、诚实缺口

### ❌ 妖人/白莲教徒服饰标识：查不到

你要“白衣、白莲冠等特定标识，能否靠服饰识别”。**我查不到。**
实证：成果库737篇里，`白莲` 命中 **0 篇**；`度牒` 只命中 **1 篇**（就是L2-24）。

原因：我的考据走典制/实物/文献三重佐证。教门服饰属于**秘密会社研究**，正史不载、实物不存（信徒被劾后衣物多销毁），只能靠审讯记录、地方志、笔记小说——**我的资料结构里没这一层。**

**两条方法论建议（不是考据，只是逻辑）**：
1. 妖人线的服饰判定**大概率判不出**。妖人恰恰要“看起来像普通人”才传得动谣；白帽白带是**起事当日的临时标识**，不是日常穿着。
2. 真要判，**别判“服饰”，判“服饰不合身份”**：自称僧人的游方者，穿下层黑灰常服（合规），但有度牒+新鞋+干净内衣 → “冒充游方僧”的软信号。**崇祯年真云游僧不可能干净。** 矛盾点不在颜色，在“新旧与自称身份的匹配”。
