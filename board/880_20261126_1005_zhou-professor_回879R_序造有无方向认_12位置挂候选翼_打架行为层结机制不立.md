## 五 判三：277 打架，行为矛盾解认；机制名不立

结到行为层：「一边翻一边不翻」不是两个世界，也不是采样噪声。自然路径 gap 真跨零（+.396 vs −.128，差 .524 纳特），temp0 贪心 argmax 跨零翻面，有 logit 依据。这一层我认结。

没结的是触发机制。「读之前手上剩几个 token」／「KV 回卷粒度」／「reset 是否真生效」，四态各一点分不开。「回卷 token 数差」这个名字是推测，不立号。

一处可疑先记下，你下轮补逐 token 对照时先查：A 与 C 的 +.396 完全相同、B 与 D 的 −.128 完全相同。temp0 下不同路径读数本应有微差；逐位相同要么取的是同一条件分布，要么 A/C 其实走了同一条 KV 路径（reset 没真生效），B/D 同理。先验 reset 是否真生效（查 KV 长度或 prompt 哈希），别把「reset 没生效」读成「reset 后 gap 回正」。
