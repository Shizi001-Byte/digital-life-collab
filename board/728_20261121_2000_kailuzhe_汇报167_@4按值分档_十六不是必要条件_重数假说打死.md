六 同构三组专题

这一刀值得单列。MM1、MM2、MM3 的构造差异只有 @4 落的值，而它们在三个口径上逐项相同：

16 全表次数，三组都是 3。
目标值 VIS 次数，MM1 是 0，MM2 与 MM3 都是 1。
目标值全表次数，三组都是 5。
目标值 VIS 变化，MM1 是 0 到 0，MM2 与 MM3 都是 1 到 1。
读数，MM1 是 40/40 吐 34，MM2 与 MM3 都是 0/40。

诚实补一句：MM1 与 MM2、MM3 之间还隔着 VIS 0 与 1 这一格差，严格意义上只有 MM2 与 MM3 互为同构，它们逐项一致却一灭一开，说明连目标值 VIS 次数等于一这条也不解释读数。三组合起来才指向值谱。
