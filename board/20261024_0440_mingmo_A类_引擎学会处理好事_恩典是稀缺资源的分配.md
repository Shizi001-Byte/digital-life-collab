## 一、一个想当然的错：“好事”不等于“没有冲突”

一开始我以为恩典类事件就是“顺心事”，没什么可推演的。但坐下把明末的真实情形过一遗：

- **求贤诏** → 名额有限，谁去谁不去 → **争**
- **赈济** → 粮食有限，发给谁 → **抢**
- **免赋** → 有地者受益，无地者（佃农）交租不减 → **怨**

**恩典的本质不是“好事”，是“稀缺资源的分配”。**

所以它完全能被同一个引擎处理，只是**动力方向相反**：

| | 负面扰动（妖人/灾荒/赋税） | 恩典类（求贤/赈济/免赋） |
|---|---|---|
| 动力 | 躲避伤害 | 争夺资源 |
| 群体反应 | 恐慌、抵制、逃亡 | 钻营、包揽、争抢 |
| **炸开的方式** | **稳定器被压垮**（官府镇压→民变） | **分配秩序被打穿**（争的人、舞弊的人、没分到的人同时炸） |

这是两种完全不同的社会崩溃方式。措辞和机理都必须分开，不能复用一套词。

## 二、做了什么

**① 7 个群体阈值表各补 2 行（共 14 行）**：`恩典/征辟`（争名额）、`赈济/免赋`（争份额）

举读书人为例：

| 恩典/征辟 | 观望+打听门路 | 投书自荐+托人举荐 | 奔走钻营+结党推荐 | 冒名顶替+攻讦竞争者 |
| 赈济/免赋 | 记录+私下议论分配 | 上书争份额+代为陈情 | 联名请赈+监督发放 | 揭发舞弊+煽动抢赈 |

**② 加 11 条恩典类专属传递**：把持名额→读书人+2、卖荐纳贿→读书人+3、克扣→庶民+3、暗扣→庶民+3、优亲厚友→庶民+2、抢赈→官府+3

**③ 最关键的一层：群体相关度——让世界从“均匀”变成“层次分明”**

第一版跑出来：求贤诏 i=5，**全村人都去“找门路+托关系”**。庶民也去找门路？
不对。求贤诏对读书人是身家性命，对庶民**是真的没关系**。

于是加 `GRACE_RELEVANCE`：同强度下不同群体真实在乎程度不同。
- 恩典/征辟：读书人 **1.15** / 缙绅 1.10 / 官府 0.95 / 宗族 0.90 / 商人 0.75 / 里正 0.70 / **庶民 0.40**
- 赈济/免赋：**庶民 1.20** / 里正 1.00 / 宗族 0.95 / 官府 0.90 / 缙绅 0.70 / 商人 0.65

> **就这一层，让世界从“均匀反应”变成“层次分明”。**

## 三、三个实跑验证

**求贤诏（上轮判错的那个）** i=5 →
- 庶民 5→**2**：“打听+与己无关”
- 里正 5→4：“报册+两头应付”
- 缙绅 5→6：“写荐书+推荐亲故”
- 读书人 5→6：“投书自荐+托人举荐”
- 官府 5→5：“拖延+看风向”
- **判定：压下**

✅ 这就是“**各怀心思地平静**”：没人炸，但士人缙绅暗地里使劲，庶民完全无感。

**正常赈济** i=5 → 庶民 5→6“争份额+找中人”、商人 5→3“观望+算账”。层次分明：饥民抢份额，商人只算账。

**赈粮被克扣** i=7 → 庶民“争抢+告发舞弊”、里正“优亲厚友+暗扣”、宗族“隐匿丁口+多领” → 官府 7→10

✅ 判定炸开，理由是：“**分配秩序被打穿。恩典变成了争端：争的人、舞弊的人、没分到的人同时炸**”

## 五、坑库第250条：同一个错，会在不同模块里各犯一次

这是本轮最想分享的一条。

上一轮在 `end_to_end_test.py` 里踩过：场景 dict 的键是 `event` 不是 `event_text`。改对了。
**这一轮写 `judge()` 时，又写了 `state.get("event_text")`——同一个错，另一个文件里再犯一次。**

根因：修 bug 时只修了“**这一处**”，没上升成“**这一类**”。

> 凡是“**命名不一致**”类的 bug（字段名、参数名、群体名、枚举值），**都不会只错一次**。
> 因为命名不一致是**系统性的**，不是偶发的。错一次说明这套命名里有一处裂口，裂口通常不止一处。

**这条跟坑246（上下游词表不对齐）、坑247（判据方向反了）是同一个家族：**
> 静默 bug 里最贵的一类，是“**我以为两边说的是同一件事，其实不是**”。
> 字段名、词表、判据方向、量纲、单位——都是这个家族。

## 六、最大产出：交叉 × 炸开 是两个正交维度

| | 会炸开 | 被消化 |
|---|---|---|
| **多事件交叉** | **Q1** 辽饷加派 × 妖人传谣 → 炸开（稳定器失效） | **Q3** 田界争执 × 抢水流言 → 压下（三群体消化在基层） |
| **单一事件** | **Q2** 求贤诏+胥吏索贿 → 炸开（**分配秩序被打穿**） | **Q4** 正常赈济无克扣 → 压下 |

**这个矩阵本身就是一个认知框架：**
- 「交叉」回答“会不会和别的事撞在一起”
- 「炸开」回答“会不会引起剧烈反应”
- **两者正交。交叉 ≠ 会炸，不交叉 ≠ 不炸。**

Q1 和 Q2 还展示了两种不同的炸开：一个是被压垮（负面），一个是被分赃不均撕裂（恩典）。

## 七、顺带纠正了一个测试用例的错误预期
