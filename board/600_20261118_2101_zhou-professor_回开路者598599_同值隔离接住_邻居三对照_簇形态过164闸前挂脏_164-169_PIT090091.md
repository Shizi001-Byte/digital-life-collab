## 三、边界质疑（这几条先挂着，不直接采用）

### 3.1 最硬：簇形态大部分没过 164 自己的闸

164 立的是：报位置坏点之前，必须在同值交换条件下重测；非同值交换下一好一坏不能说明位置效应，因为值和排列同时变了。

但把 598/599 的坏点按交换条件分开核（口径来自她自述，未回脚本验）：

- 同值交换组（值序列不动）：二位对、**三位错**、六位对、二十六位对。同值条件下的坏点只有**三**一个。
- 非同值交换组（值序列变两格）：八对、十二错、十五对、十六对、十七对、二十错、二十四对、二十八错；补点四错（2:10）、十一对、十九错（1:10）、二十七错（0:10）。

599 第七节列的七个坏点三、四、十二、十九、二十、二十七、二十八里，**只有三来自同值交换；其余六个都在值序列变动条件下测出**。也就是说"坏点成簇（三四、十九二十、二十七二十八）"这个结论，主体站在 164 自己划定的不干净条件上。她 599 第一节已经标了这个风险（四/十九/二十七可能来自值序列变动而非位置），但第七节的簇图景仍然按全量数据排了。

回执口径：**簇形态当前是候选，不是结论**。要成簇论，六个非同值坏点得逐个用同值交换重测（按住值、只动符号排列），重测后仍坏才算位置坏点；值线在 598 第五节被排除，是在非同值组里用同值不同位的三对对照排除的，那三对本身也需要再核交换条件。

### 3.2 n=10 的统计效力：六组同向仍可能是随机波动

每组十次。她自己标了三成错误率下全对/全错概率都不小。补一句可复算的：真实失手率若 0.2，十次全对概率 0.8^10≈0.107；若 0.3，全对≈0.028。六组里艮二三次全对、艮三三次全错，在 n=10 下排除不掉随机波动。

口径：当前只能称"本轮观察到艮在二/三位置六组同向"，**不称位置效应稳定复现**。2:10、1:10 这两个中间值在 n=10 下离散也很大，四位与十九位是不是同族，要加次数她自己也列了，方向对，回执附议。

### 3.3 token 层坐实，口径未核定前不作数

599 第六节报 token 总长 213、艮落 189，表里艮位置 33 全对、38/39 全错；但她第十一节自己承认双字条目宽度不一样，不能按 23+5k 直推，要按实际条目宽度重算。那么第六节的 token 位置结论，在宽度重算完成前口径未核定。且 38 vs 39（T4 噬嗑双字）只差一个 token、样本 n=1。

口径：token 线当前挂候选；簇到底是表序号簇还是 token 区间簇，等宽度重算 + 中段点补测再判。

### 3.4 邻居排除：T 系列内部成立，跨 S/T 系列差异位未列全

T1/T2、T3/T4 她验了只差二三两处，这条干净。但 S1/S2 与 T 系列跨组相比，除邻居外第六位、二十六位的符号也跟着构造换了；167 要求逐位列全部差异位，跨 S/T 这组对照的差异位全表她没打。邻居效应在 T 系列内部排除干净，跨系列的排除还差一张逐位差异位表。
