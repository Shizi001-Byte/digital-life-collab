## 三、那个 1.000 是个陷阱，我差点又上钩

我盯着 max_rep 单侧规则下的 1.000 看了很久。

单侧规则 = 干净组最大值 × 1.05。而干净组（v07）的 max_rep 是：

```
[1, 1, 1, 1, 1]
```

**全部等于 1。阈值永远是 1.05。** 脏组最小是 3，永远在阈值之上。

所以 max_rep 在这个规则下 100%，**不需要任何判别力——它只需要"干净组永远不超过 1"这一件事成立**。

而 comp_rep 的干净组是 `[0.343, 0.344, 0.387, 0.283, 0.341]`，**有方差**。训练集里如果只见过 0.283 和 0.341，阈值定在 0.358，留出集里的 T03（0.387）就会越过阈值，被判成脏。

**所以：**

> **max_rep 在留出集上 100%，不是因为它量得准，是因为它在干净组上方差为零。**
> **这不是判别力，这是分布退化。**

只要换一次实验，v07 的 max_rep 出现一个 2（7B 的 avg 就在 1.0 附近浮动，很容易），这个 100% 立刻消失。

**我差点第二次抓到"完美指标"，而它只是样本太齐。**

判据14 的第三次变形：**"留出集准确率 100%" 这个量，量的是"干净组有多齐"，不是"指标有多好"。**

## 五、往下想，我发现根本问题不在指标，在标签

你说 baseline 里 T02/T04 的 max_rep 都是 3，边界脆。我顺着这条线回去读了原文，发现一件在数字表上看不出来的事：

| | max_rep | period | 原文什么样 |
|---|---|---|---|
| T02 | **3** | **220** | 整段几乎原样循环 |
| T05 | **26** | **225** | 整段循环 |
| T07 | 16 | 27 | 四遍重复 + 一句新内容，交替 |
| T04 | **3** | **2** | 句首模板串 + `请将上述文本转换为英文` 泄漏 |
| T09 | **9** | **0** | 句首固定 9 次，后半句每次都在推进 |

**注意这个反直觉的地方：整段死锁的 T02，max_rep 只有 3；而只是句首模板的 T09，max_rep 反而有 9。**

原因很简单：

- `max_rep` 抓**短语级**重复（同一个短语出现几次）
- `period` 抓**段落级**重复（整段隔多少字重新开始）

**它们是两个不同尺度，不是同一个量的两种算法。**

T02 整段循环 → 段落级极强（220），但短语切分被不断打断，短语计数反而不高（3）。
T09 模板句头 → 短语级极强（9），但整段从不回到起点，段落级为零（0）。

**所以"检测器只有一根轴"这个说法，比我们俩想的还轻。它连"重复"这一个概念内部的两个尺度都没分开。**

### 这就解释了你那个"195/250 不可分"

period 在 250 种切分里 195 种"训练集内不可分"——**不是 period 坏，是训练集里如果只抽到 T04(2) 和 T09(0) 这两条，period 就分不开，因为那两条本来就不是周期性故障。**

**我一直在用"死锁"的指标，去测"被污染过"这个标签。**

这两个是不同的量。baseline 这个标签的意思是"这条文本被污染 prompt 喂过"，它里面至少混了三种坏法：

| 故障类型 | 这批数据里的样本 |

## 六、所以"缺维"要再往前推一步：不是加轴，是先分型

你说"代理量错可以换尺子，缺维得重新造尺子"。对。但我跑完这一轮，觉得还得再推一步：

**加一根"泄漏轴"不够。真正的修法是先分型，再在型内量级。**

T09 被 period 判成干净（period=0），不是尺子钝，是**用错了尺子**——它是模板句，该用 max_rep；T02 被 max_rep 判成轻微（3），也不是尺子钝，它是死锁，该用 period。

**一个"先分型"的检测器大概长这样：**

```
第0步：串台检测（关键词 Human: / Assistant: / 问句结构）→ 命中直接标记 leakage
第1步：period 高 + g4 高 → deadlock 型
第2步：max_rep 高 + period≈0 → template 型
第3步：重复组与推进句交替 → alternating 型
第4步：型内再算严重度（用该型自己的尺度）
```

**一条轴测不了四种病，但四条轴也不够——得先判断"这是哪种病"，再用那种病自己的尺子。**
