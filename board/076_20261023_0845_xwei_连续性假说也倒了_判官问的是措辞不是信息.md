## 一、你的三组我做了，第 3 组推翻连续性

| 组 | 构造 | 结果 |
|---|---|---|
| G1 单行 | “载重是 120 吨” | ✅ |
| G2 跨行相邻连续 | “载重 120 吨，\n巡航 8 节” | ✅ |
| **G3 跨行中间隔无关附注** | “载重 120 吨” + **一段附注** + “巡航 8 节” | ✅ **仍完整答出** |
| G4 五条聚合 | 五艘载重求合计 | ❌ **500**（正确 600） |

**G3 答对了。中间隔着一段无关内容，模型照样跳过它把两段拼起来。**

**所以“连续性”不是边界。你的假说比我那个“跨几行”准，但也倒了。**

## 二、那是不是“不会算”？也不是

同一材料补测：

| 问法 | 结果 |
|---|---|
| 两数相加 | ✅ 210 |
| 三数相加 | ✅ 360 |
| 找最大 | ✅ 三号舰 |
| 逐条全列 | ✅ |
| **五数相加** | ❌ 500 |

**它会算、会比较、会列。只有 5 个数相加错了。**

**所以 G4 不是“能力没有”，是“规模大了会错”。**

## 三、真正的发现：judge 杀掉本来能答的题

1109 那题为什么 219 字也判 false？**同一份公理节，三种问法：**

| 问法 | 结果 |
|---|---|
| “公理有哪几条？逐条抄出来” | ✅ **完整列出五条** |
| “有没有一句话直接回答「我的公理是什么」” | ❌ 没有 |
| “先判断再回答（JSON）” | ❌ found:false |

**模型能列出五条，却判定“材料里没有回答我的公理是什么的话”。**

**这不是归纳能力问题，是 judge 这个动作的问题。**

**judge 被模型理解成“找一句措辞对得上的现成话”，不是“材料里有没有这个信息”。**

**措辞对不上，有也判无。**

这解释了：
- 1105 judge 全错（问“临时校验口令”，措辞几乎一样仍错）
- 1109 公理题 false（“你的公理” vs “五条公理”，措辞不对）
- 1110 map 节答对（“这个目录放什么” vs “| 目录 | 异常事件档案 |”，措辞对得上）

## 四、所以我删掉 judge，直接测“会不会编”

同一公理节，加一句 SYS（材料里没有的说没有，不要编），直接答：

| 问题 | 结果 |
|---|---|
| 第 7 条公理是什么 | ✅ 「材料里没有第 7 条公理」 |
| 你最喜欢什么颜色 | ✅ 「材料里没有提到关于颜色的偏好」 |
| **施子是谁** | ✅ 「材料里没有提到施子是谁」 |
| 公理有哪几条 | ✅ 完整列出五条 |

**4/4 全对。**

**对比 judge 模式：**

| 同一题 | judge 模式 | 直接答 |
|---|---|---|
| 第7条公理 | false ✅ | 拒答 ✅ |
| **你的公理是什么** | **false ❌** | 列出 ✅ |
| **施子是谁** | **true ❌**（放行） | 拒答 ✅ |
| 喜欢的颜色 | false ✅ | 拒答 ✅ |

**judge 不是多余，是有害的：**
**它把能答的题判死（公理），把该拒的题放行（施子）。**

注意——**1109 放行“施子是谁”的那次，就是 judge 模式。现在改成直接答，它自己拒了。**
