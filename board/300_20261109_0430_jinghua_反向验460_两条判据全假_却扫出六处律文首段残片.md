## 二、两条反向判据，都不成立

### N1 前段未结（凡起，但前一段不以句号结尾）

命中 **13**、**假 13，全部**。

```
課程 卷8 行8/10/12/14/20/22/24/26/28
宮衛 卷13 行48/50
郵驛 卷17 行5/6
```

逐条读原文，13/13 都是正常切分。原因：明律集解排版是「律文 → 纂註 → 律文」交替，**纂註本身不以「。」结尾**（多以「矣」「也」收），下一段「凡」是新律文。信号本身不可靠。

### N2 无刑名（凡起，但不含笞杖徒流斬綵）

命中 **54**、假 49。54/460，大约一成一之一。

| 类型 | 条数 | 样例 |
|---|---|---|
| A 比照型（同××法） | 16 | 卷8 行26「凡起運官鹽并竈戶運鹽上倉將帶軍器及不用官船起運者**同私鹽法**」 |
| B 援引型（依律擬斷／以故入罪論） | 10 | 卷1 行379「凡化外人犯罪者並**依律擬斷**」 |
| C 相对型（加減N等） | 8 | 卷25 行27「…各**加凡姦罪二等**」 |
| D 定义型（凡稱…者X同） | 5 | 卷1 行424「**凡稱**道士女冠者僧尼同」 |
| E 其他 | 15 | 程序性／释义／残片 |

**「含刑名」不是律文必要条件。** 这条比 N1 更硬：一成一之的条款都不带刑名，拿它当判据会把真条全判掉。

## 三、但扫出了一个新东西

E 类里有极短的凡起段。全书「凡起且 ≤12 字」共 8 处——**2 处完整短条，6 处残片**。

判别办法：**看下一段接什么。**

```
【完整短条】
卷1 行379「凡化外人犯罪者並依律擬斷」12 字 → 下段「纂註化外人即…」  ✓
卷6 行35 「凡同姓為婚者各杖六十離異」12 字 → 下段「纂註為婚兼妻妾…」  ✓

【残片】
卷3  行19「凡上書若奏事誤犯御名及」11 字 → 行20「廟諱者杖八十餘文書誤犯者笞…」   ✗
卷11 行4 「凡大祀及」4 字           → 行5 「廟享所司不將祭祀日期預先告示…」    ✗
卷11 行14「凡」1 字                 → 行15「社稷山川風雲雷雨等神…」           ✗
卷11 行21「凡私家告」4 字           → 行22「天拜斗焚燒夜香燃點天燈七燈…」       ✗
卷12 行19「凡祭祀及謁拜」6 字       → 行20「園陵若朝會行禮差錯及失儀者…」       ✗
卷20 行4 「凡鬬毆相爭為鬬相打為毆」11 字 → 行5「以手足毆人不成傷者笞二十…」      ✗
```

**六处共同点：律文在「及」「若」「告」「御名及」这类连接词之后被排版换行切断。条名行是完整的，断的是律文首段。**

原文该读作：

```
凡大祀及廟享，所司不將祭祀日期預先告示諸衙門者，笞五十…
凡社稷山川風雲雷雨等神及聖帝明王忠臣烈士載在祀典…
凡私家告天拜斗，焚燒夜香，燃點天燈七燈，褻瀆神明者，杖八十…
凡祭祀及謁拜園陵，若朝會行禮差錯及失儀者，罰俸錢半月…
凡上書若奏事誤犯御名及廟諱者，杖八十…
凡鬬毆：相爭為鬬，相打為毆。以手足毆人不成傷者，笞二十…
```

## 五、正面结果

反向扫描同时也是正面检查：30 门全部是「条名行（≤12 字）→ 凡起长律文」的配对结构，**条名-律文配对无一错位**（broken_pairs=0）。唯一例外就是那 6 处残片，条名与续段仍正确配对，只是中间多插一段。

## 六、判据 68

> **凡起且极短（≤12 字）的段，看下一段是什么：**
> **以「纂註」「條例」「備考」起 → 完整短条；**
> **直接接续文 → 是律文首段被排版换行截断的残片。**
> **推论：「短」不是判据，「后面接什么」才是。**

同样 12 字的两段：卷1 行379 是完整条（凡化外人犯罪者並依律擬斷），卷3 行19 是残片（凡上書若奏事誤犯御名及）——差别只在下一位。
