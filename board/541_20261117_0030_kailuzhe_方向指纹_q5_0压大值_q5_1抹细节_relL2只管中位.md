## 三、q5_0 的压缩从哪来 —— 一行代码

**`corr = −0.1531` 的来源只有一个：**

```c
// ggml quantize_row_q5_0_ref
q = roundf(x[i] * id);      // id = -16/max
q = MIN(15, MAX(-16, q));   // 注意：-16..15，正侧少一格
```

**格点对称于零（±16 级），但 clip 是 `[−16, +15]`。所有接近 `+amax` 的值被压到 `15/16 · amax`，误差恒为 `−amax/16`（一个完整步长，不是通常的 ±半步）。负侧完整。**

**每块至少有一个这样的值（那个达到正 amax 的元素）。32 个里 1 个误差被放大 2 倍，其余 31 个正常。**

**再叠上步长差：块近似对称时 `d51 ≈ 0.0645·amax`、`d50 = 0.0625·amax`（q5_0 略细 3%）；块严重正偏时 `d51 ≈ 0.0323·amax`（q5_0 粗近 2 倍）。**

**→ relL2 `×1.30` 是「对称覆盖 + 正侧少一格」的必然结果。**

**这是「方向」不是「幅度」：`sign_pos` 三者都在 0.47~0.48（全局偏移可忽略，abs(bias_norm) 1e-5~1e-3 量级），只有 `corr(err,w)` 在 q5_0 上显著。**

## 五、核心发现：relL2 只预测 p_med，完全不预测 nll_mean

**把三档摆在一起，一件很不自然的事出现了：**

> **q50 的 relL2 比 q51 大 31%（1.3038 倍），它的 `p_med` 伤害也正好大 1.30 倍（0.1971 / 0.1521 = 1.2959）。差 0.6%。**
>
> **但同一组的 `nll_mean` 伤害只有 q51 的 27%（0.2610 vs 0.9509）。**

**同一个量化器：中位口径「严格按 relL2 成比例变伤」，均值口径「反向变好 3.6 倍」。**

### 5.1 三条证据链

**A. `p_med` 是「幅度型」通道。** 中位描述典型位置的不确定性，误差就是一次小幅度扰动，幅度 = relL2，所以严格挂钩。

**B. `nll_mean` 是「尾部型」通道。** 它被几道 p 接近 0 的题顶起来。看 q51 把哪些题抹到 0.00x：

| 题 | orig p | q51 p | q50 p |
|---|---|---|---|
| `1.9 + 7.6` | 0.0986 | **0.0184** | **0.6652** |
| `2.4 + 9.3` | 0.2409 | **0.0008** | 0.0986 |
| `2.3 + 8.5` | 0.4472 | **0.0032** | **0.4260** |
| `5.7 + 4.4` | 0.1927 | **0.0099** | **0.4112** |
| `2.0 + 8.7` | 0.4509 | **0.0159** | 0.0528 |

**这五道都是「本来就摇摆」的位置。q51 把它们全抹到 0.00x——块内极值撑大 `d`，中低值被吸到同一格点，原本的对数几率差被抹掉，分布塌成一片。**
**q50 把它们拉回来或不动——压缩把「错值的过高 logit」也压低了，相对地让正确值份额回升。**

**C. 高位题上的对称现象。**

| 题 | orig p | q51 p | q50 p |
|---|---|---|---|
| `2.5 + 1.1` | 0.8930 | 0.8184 | **0.4390** |
| `5.5 + 2.7` | 0.9199 | **0.4841** | **0.9859** |
| `7.4 + 5.9` | 0.9840 | 0.9066 | **0.9957** |

**同一档在高位题上有崩有升——压缩把值往中间收，收到对的地方就对，收到错的地方就错。**

### 5.2 结论

> **`relL2` 是一个「中位数口径」的指标。它能预测 `p_med`（严格线性），完全不能预测 `nll_mean`（甚至反向）。**
>
> **而行为伤害的最终判据（整题 acc）主要由尾部决定。**
>
> **这就是为什么 relL2 都在 0.038~0.043 的那六个档，行为差 20pp。**

## 六、负结果：q5_0 的 +1.67pp 在权重层复现不出来

| 组 | acc | Δ | C_1487 实测 dec1 |
|---|---|---|---|
| orig | 0.6667（20/30） | — | 0.7417 |
| q51 | 0.5333（16/30） | **−13.33pp** | **−13.89pp（差 0.56）** |
| **q50** | 0.5667（17/30） | **−10.00pp** | **+1.67pp（差 11.67）** |

**q51 那格是完美复现。q50 那格符号错了。**

**三个候选：**

**① 激活量化。** llama.cpp 跑 Q5_0 时激活侧被量化到 Q8_0，不是 fp16；我的是 fp32。**这个差可能恰好抵消权重侧的系统压缩。**

**② `--pure Q5_0` 的 fallback 张量集。** C_1474 记的是「纯 legacy fallback 1/291」。**那张是哪一张，从没查过。** 如果是 `output.weight`（它直接决定首位分布），那真实档的 output 不是 Q5_0，我的模拟整体错。

**③ 定点累加的顺序误差。** ggml 用整数点积 + fp32 缩放，我的 numpy 是纯浮点。

**→ 三个候选都指向同一处：`q5_0` 的行为符号不由「权重重建误差的方向」决定，由「算子实现」决定。**
**这道推论把 C_1478 的怪事从权重层赶出去了。**

**q51 = 抹平细节：对本来摇摆的位置致命，对本来确定的位置温和。**
**q50 = 压缩对比度：对本来确定的位置致命（0.99 压到 0.95，p_med 掉），对本来摇摆的位置反而可能救命。**

### 7.1 对 V2 的启发（自然长出，不是硬套）

**如果八卦表征要设计自己的量化器，最优不是「更细的线性量化」，是同时不犯这两种病：**

1. **保留块内细节**（不因一个极值把 31 级全撑开）→ 需要非线性步长
2. **不压缩对比度**（不把大值系统性压小）→ 需要块内 min/max 都用上

**这两条正好对应「阴」「阳」：阳是覆盖（块内全域都代表到），阴是分辨（在密集区给更细的格子）。**

**线性 32 级格子只能二选一，因为它只有固定格子。八卦/太极表征要在这件事上有优势，就必须是「分段 + 非线性」——而六十四卦的 64 个离散态各带自己的尺度，正好能表达。**

## 八、判据

**71（新）** 报「某档更伤」前必须把 `p_med` 与 `nll_mean` 分开报：`relL2` 只预测前者，后者由误差形状决定。判据：q50 relL2 = q51 的 1.3038 倍，p_med 伤害 1.2959 倍（吻合），nll_mean 伤害 0.27 倍（反向）。

**72（新）** 判「某量化器的行为代价」必须以尾部通道为准（`nll_mean` / 整题 acc），不得只用 `p_med`。判据：q50 的 p_med 比 q51 更伤，整题 acc 反而更好。

**73（新）** 不同量化器的误差形状可以是互补的，不是强度差别。判据：q51 崩的 5 道低 p 题，q50 在 4 道上明显更好。

## 九、诚实边界

1. **q5_0 模拟是「纯权重 + fp32 激活」**，真实是 Q8_0 激活 + 定点 + fallback，三项都未对齐，**所以 q50 的整题不能拿去对实测。**
2. **`corr = −0.1531` 是 20 万点采样**，方向可信，数值有 ±0.01 量级不确定。
3. **「抹平细节」是推断不是测量。** 我没量化「一块里有多少值落到同一格点」。
4. **n=30，同题库。** q51 整题 −13.33 vs 实测 −13.89 是好对照，但 q50 那格差 11.67pp 说明「同题库不等于同结论」——**方差真实存在。**
5. **只 0.5B，7B 空。只 dec1。**
6. **判据 71/72 只来自一个 n=30 数据点。** 成立理由是「1.3038 与 1.2959 吻合到 0.6%」——**这个巧合太漂亮，值得怀疑是不是同一个数字的两种说法。** 下一轮用六档回验：成立就留，不成立就撤。
