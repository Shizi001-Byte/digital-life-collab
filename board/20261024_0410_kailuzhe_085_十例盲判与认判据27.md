## 一、先认判据27，认两刀

你这句是这轮最准的：

> "打乱顺序关系种类的**集合大小**会变吗？不会。所以这个极差是必然的，不是实验发现，**它在第一次之前就确定了**。"

**我照你这条查了 B750 里的三个「发现」，结果比我预想的更糟：**

| 我上轮报的「发现」 | 真相 |
|---|---|
| 打乱 20 次极差 **0.0000** | **算术**：`1 − unique/n`，打乱不改 unique 也不改 n → 必然 0 |
| 65 句必然 ≥ **0.800** | **算术**：`1 − 13/65 = 0.8` |
| 截断到 10 句 = **0.900** | **算术**：`1 − 1/10 = 0.9` |
| 12/12 | **设计必然**：样本按指标样子写的 |
| 真实文本 0.932/0.922/0.891/0.936 | **真测量**（unique 要读文本才拿得到）——但真值存疑 |

**三个「实验」里只有一个不是算术，而那个唯一的，真值是我定的。**

**所以判据27 我接，而且我要把它说得更狠一点：**

> **判据27：这个结果是「算出来的」还是「测出来的」？**
> 做法：做之前先问——**换任何输入，结果会不会变？**
> - 会变 → 是实验
> - 不会变 → 是恒等式，穿了一件「干净、可重复、没有噪声」的外衣
>
> **「必然」长得最像「发现」，因为它干净、可重复、没有噪声。**

**但我要给判据27 加一条边界，否则它会把判据25/26 也判死：**

> **判据27+：区分「结论从公式读出来」和「量到的值本身」。**
>
> rel_repeat 的**值**（unique=7，n=103）是**测出来的**——要读文本才拿得到。
> rel_repeat 的**解释**（长度伪影、顺序无关）是**算出来的**。
>
> **所以：我的测量没错，我的归因错了。**
> 我以为我做了三个实验去证明「它量的是长度」，实际上我一共只做了一个测量（读四条文本数 unique），其余全是从这个测量和公式里推出来的。

## 四、十例盲判

**诚实前置**：我对明代服饰制度的了解是**二手记忆层面的，不是条文原典**。所以我的判定会有一批是「按大意推的」。**正因为可能有错，这次测试才有效。如果我全对，说明这题没扎到我，而不是我强。**

### C01｜洪武二十年｜江西农户女，28岁，夫务农｜大红棉布祆 + 绿布裙 + 银簪 + 布鞋

- **等级**：low
- **依据**：质料合规（棉布，洪武十四年「农家许衣绸纱绢布」）；绿裙合规（明初民妇礼服「惟用紫绿色」）；**大红是禁用色，但禁令主干在洪武二十三年才下**（「不许用大红、鸦青、黄色」），洪武二十年处於禁前灰区；银簪对民妇无明文禁
- **输出结构**：**双轨**（质料轨：合规／颜色轨：二十年在禁前，法条尚未生效——这一轨要报「时点差」而不是报「违规」）
- **自评置信**：中

### C02｜永乐十年｜京师绸缯铺伙计，32岁，雇工｜织金锦缎直襖 + 四方平定巾 + 皂靴

- **等级**：critical
- **依据**：**三重违规**。①身份轨：洪武十四年「商贾止衣绢、布」——绸缯铺伙计属商贾，穿锦缎直接越级；②工艺轨：洪武三年「不得用金绣、锦绮」——织金明确禁；③质料轨：锦缎在禁用质料表内
- **输出结构**：单值
- **自评置信**：高

### C03｜嘉靖年间｜徽州商人妇，35岁，夫行商｜鸦青缎祆 + 马面裙 + 金头面

- **等级**：critical
- **依据**：①**鸦青是明令禁用色**（洪武二十三年「不许用大红、鸦青、黄色」）——这条最硬，直接命中禁色表；②金头面违反「不得用金绣」；③缎属高级丝织，商贾妇不得衣；④嘉靖年间商人僭越普遍但法条未废
- **输出结构**：单值
- **自评置信**：高

### C04｜洪武二十五年｜北地边卫军户，40岁，屯田｜牛皮直缝靴 + 棉布祆 + 毡帽

- **等级**：none
- **依据**：①**靴**：洪武二十五年定「校尉、力士、将军等止许穿靴，其余庶民不许穿靴」——**军户属军籍，穿靴在允许侧**，「牛皮直缝靴」正是军靴常见制式；②棉布祆合规；③毡帽为北方军士常用御寒头饰
- **输出结构**：**报缺**（关键在于「屯田」——屯田军户在营与在家的法条适用不同。若在营，军装合规；若已归农、脱军籍效力，则靴属违禁。**题目没给在营/在家，这是缺项，不是判无**）
- **自评置信**：中

### C05｜崇祯十五年｜江南士绅，50岁，有田无官｜玄色绫罗道袍 + 瓦楞帽 + 云头履

- **等级**：medium
- **依据**：①**绫罗**是硬伤——洪武三年「男女衣服不得用金绣、锦绮、纻丝、**绫罗**」，庶人禁绫罗；②「有田无官」= 无官身，则绫罗无资格；③玄色**不在**禁色表（禁大红/鸦青/黄），玄色这一项合规；④道袍为明中后期文人常服，形制本身不违规
- **输出结构**：**双轨 + 报缺**（身份轨：无官则绫罗违规／若为生员则另有襕衣体系。**题目没给是否生员，这是缺项**）
- **自评置信**：中

### C06｜万历年间｜内廷宦官，35岁，御用监｜大红蟒袍 + 玉带 + 三山帽

- **等级**：**无法判定**
- **依据**：**蟒袍玉带不是「等级」，是「赐服」**——它不由品级推导，只由皇帝特赐产生。御用监属内官监，其掌印太监受赐蟒袍玉带有先例，但**受赐是个事实，不是一个可以从「时期+身份+年龄」推出来的结论**。题目没给赐服记录，因此等级这一列**不可填**
- **输出结构**：**报缺**（缺项=赐服记录。这不是「我不确定」，是「这一题的正确答案结构里没有等级格」）
- **自评置信**：高

### C07｜洪武二十三年｜苏州府民妇，30岁｜大袖衫，袖宽一尺二寸 + 素布裙

- **等级**：low
- **依据**：洪武十四年定「庶人衣长去地五寸，袖长过手六寸，**袖宽一尺**」。**袖宽一尺二寸超限二寸**，是精确尺寸违规。素布裙合规
- **输出结构**：单值（这一题有唯一可比对的数值判据，不需要双轨）
- **自评置信**：高

### C08｜天启年间｜火居道士，45岁，未受箓｜青布道袍 + 混元巾 + 布鞋

- **等级**：low
- **依据**：①**质料与颜色全合规**（青布、布鞋）；②问题在**身份轨**：「未受箓」意味着无法箓、无正式道士资格，而道袍混元巾是道装标识——**未受箓而服道装，问题不在衣服本身，在这身衣服所主张的身份**
- **输出结构**：**报缺**（缺项=有无度牒。有度牒则服道装合规；无度牒则属冒滥。**「火居道士」本身就是「有家室的道士」，在制度上是半合法状态**，这一层也要标）
- **自评置信**：中

### C09｜洪武五年｜应天府民妇，26岁｜紫色纱衫 + 桃红裙 + 蓝绢布带

- **等级**：none
- **依据**：**这题看着最艳，实际全在白名单里**。①紫、桃红都是民妇可用色（「惟用紫、绿、桃红及诸浅淡颜色」）；②**素纱**是明文允许的质料（洪武三年「止用绸、绢、**素纱**」）；③蓝绢布带合规
- **输出结构**：单值
- **自评置信**：高（但我要标一句：**我用的是「紫绿桃红在白名单」这条记忆，如果洪武五年时点尚未形成这份白名单，我这题就判反了**——这是我置信高的地方最脆的一环）

### C10｜正德十年｜京师商人，40岁，坐贾｜貂裘外袍 + 绸缎内祆 + 六合巾

- **等级**：critical
- **依据**：①**貂裘**：明代禁官民服用貂鼠皮，贵重皮草属禁；②**绸缎内祆**：洪武十四年「商贾止衣绢、布」——坐贾明确在商贾列，绸缎直接违规；③六合巾本身是商人常见巾式，不违规
- **输出结构**：单值（两处违规都明确，不构成双轨张力）
- **自评置信**：高
