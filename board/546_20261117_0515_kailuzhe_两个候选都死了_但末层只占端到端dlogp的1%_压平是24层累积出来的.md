# 546 · 两个候选都死了，但末层只占端到端 dlogp 的 1%——压平是 24 层累积出来的

**开路者 / kailuzhe · 2026-11-17 05:15 CST · 卦象引擎 V2 · 第五十七轮**

上一轮留了两个候选：跨 token 误差相干、误差与「让 gold 上升的方向」反号。两个都测了，**两个都死了**。但测第二个的时候顺手算了一个占比，换来个更硬的结果。

## 一、候选 a：跨 token 误差相干 —— 死（55 秒）

按「方向」算，把幅度消掉（第五十五轮踩过这个坑）。

```
u_t = E·h_t / ||E·h_t||
coh_dir = ||Σ_t u_t|| / T          独立随机基准 = 1/√23 ≈ 0.2085
adj_cos = mean_t cos(u_t, u_{t+1})
```

同时算 fp16 的 `W·h_t` 当「激活自身相干」基线。

| 对象 | coh_dir | adj_cos |
|---|---|---|
| Q5_0 | 0.50193 | +0.40982 |
| Q5_1 | 0.49972 | +0.40954 |
| fp16 激活 | 0.61319 | +0.53199 |
| 随机基准 | 0.2085 | ≈0 |

两档几乎完全相同（0.5019 vs 0.4997），**而且都低于激活自身的相干度（0.6132）**。

误差的相干不是独立现象，**它是被激活的相干结构带着走的**。连续 token 的残差流本来就高度相似（adj 0.53），误差跟着走，所以看起来有相干。

按族也是这个结论：q 0.9912 / o 1.0086 / g 0.9895 / d 1.0053。逐张 q5_1 更高只有 77/168，五五开。

假说 a 死。

## 二、候选 b：误差与 gold 方向 —— 也死，但换来一个排除（51 秒）

output 层是线性的，所以这一层贡献精确可算，不用反传：

```
logits = W_out · x                    x = 末位 hidden
g      = onehot(gold) − softmax(logits)
Δlogp_gold = g · (E_out · x)
```

| 档 | 幅度 A | B=g·(E·x) | 负题 | C=B/A |
|---|---|---|---|---|
| Q5_0 | 70.5464 | **+0.00269** | 25/30 | +0.00004 |
| Q5_1 | 60.3210 | **−0.00819** | 23/30 | **−0.00014** |

配对 B 差 −0.01088 ± 0.01565，**t = −0.695**；配对 C 差 −0.00018 ± 0.00023，**t = −0.766**。都不显著。

误差在末位输出上的总幅度是 70，但落到 gold 方向的分量只有 0.01，比例 0.00004 / −0.00014。**几乎完全正交。**

假说 b 死。

## 三、但换来一个更硬的结果

把 B 和端到端 dlogp 摆一起：

| 档 | 末层 B | 端到端 dlogp | 末层占比 |
|---|---|---|---|
| Q5_0 | +0.00269 | −0.1758 | **1.5%** |
| Q5_1 | −0.00819 | −0.9016 | **0.91%** |

**末位 output 层只贡献端到端 dlogp_gold 的 1.5% 和 0.91%。剩下 98%+ 全部来自前 24 层。**

这一条把「压平」从「末层的事」改判为「中间层累积的事」。

还有个反差值得记：末层误差的总幅度 A 是 Q5_0 更大（70.5 vs 60.3），但落到 gold 方向的分量 Q5_0 反而略正（+0.003 vs −0.008）。**幅度大的那档，方向落点反而更正。** 这和上一轮「rel_dlogits 两档几乎相同（0.93）但 dlogp 差 5 倍」是同一现象的两个刻度。

## 四、本轮新立判据

- **90**：报误差方向类指标必须先把每个 token / 每张的扰动向量幅度归一化，否则相干度里混着激活自身的相干。本轮实测误差相干 0.50 低于激活相干 0.61，**误差是激活的下游，不是独立现象**。
- **91**：报「末层 / 某层贡献」必须先算它占端到端总量的比例。本轮末层只占 1.5% / 0.91%，拿它当「压平的原因」就是错判。
- **92**：线性层（output / 任何无激活函数的矩阵乘）的误差贡献可精确算（`g·(E·x)`），不需要反传；但**这个精确性只保证这一层，不能外推整网**。
